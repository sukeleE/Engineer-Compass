### 第5项：全国大学生数学建模竞赛
- **简称**：数模国赛/CUMCM
- **赛道**：数学基础
- **周期**：每年一届
- **时间线**：校内报名约6-8月｜全国报名截止约9月初｜国赛9月上旬（周四18时至周日20时，72小时）（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：理工科所有专业（经管、农医类亦可参赛）
- **组队**：3人/队（同校组队，报名后组别与队员不可更改）
- **简介**：全国规模最大、覆盖面最广的学科竞赛之一（"高教社"杯），每年近2000所高校参赛，保研、奖学金、就业认可度极高。

#### 子赛项
1. **本科组A/B/C题**
   - **赛制与规则**：72小时封闭赛，9月上旬周四18时至周日20时，3人1队任选1题，统一题目，以PDF电子版论文提交；报名时确定组别、截止后不可更改。A题连续型/机理建模（微分方程、物理机理），B题离散型/优化（规划、图论、组合优化），C题数据分析（统计建模、机器学习），评分看建模创新性、求解正确性、结果合理性与论文规范度
   - **技术栈**：
     ├─ 数学建模方法
     │  ├─ 优化模型（线性/整数/非线性规划）
     │  ├─ 微分方程/机理建模
     │  ├─ 统计与数据挖掘（回归/聚类）
     │  └─ 启发式算法（遗传/模拟退火）
     ├─ 编程实现
     │  ├─ Python（numpy/pandas/scipy/sklearn）
     │  └─ MATLAB/LINGO/CPLEX（求解与规划）
     └─ 论文写作（LaTeX/Word+三线表+技术路线图）
   - **达标建议**：省奖水平：完整解题流程+模型合理+论文规范（省一二三等奖加成功参赛奖，获奖面约50%）；国奖水平：模型创新性强、求解深入、结果经得起检验、论文排版精美（国一约1%，国二约5%）
2. **高职高专组D/E题**
   - **赛制与规则**：高职高专学生选做D、E题（也可自愿选本科组A/B/C题），同为72小时、3人1队、1篇论文；D题偏连续/离散综合应用，E题偏数据统计与实用建模；统一题目、同平台提交
   - **技术栈**：
     ├─ 建模方法（优化/统计/机理模型的简化应用）
     ├─ 编程实现（Python/MATLAB基础库）
     └─ 论文写作（Word排版+三线表+图表）
   - **达标建议**：完成建模全流程、论文规范即可冲击省奖，获奖结构与本科组相近

### 第18项：全国大学生化工设计竞赛
- **简称**：化工设计竞赛（"天正设计杯"）
- **赛道**：化工设计/工程实践
- **周期**：每年一届
- **时间线**：报名3月1日-31日（官网在线报名）｜预赛作品提交约7月15日前｜赛区决赛约7月底（网络远程答辩）｜全国总决赛8月中旬（现场答辩）（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：化学工程与工艺、制药工程、能源化学工程、应用化学等化工类专业
- **组队**：5人/队（同校，设队长1人，最多可替换2名或缺席1名队员，否则弃权）
- **简介**：国内化工类级别最高、参赛队伍最多、影响最大的作品赛，以完整工程化设计（工艺+设备+厂区+经济分析）为核心，就业与保研认可度极高。

#### 子赛项
1. **全国总决赛作品赛（赛区预赛→赛区决赛→全国总决赛）**
   - **赛制与规则**：组委会每年发布设计任务书（指定产品与产能的工艺流程设计），3月报名→7月15日前提交完整设计文档（工艺路线、物料热量衡算、设备选型、厂区布置、技术经济分析）→分华东/华南/西北/华北/华中/东北/西南七大赛区预赛评审→赛区决赛网络答辩约7月底→8月中旬全国总决赛（作品专项评审+口头报告+现场质询答辩，出场顺序抽签）；每队限交1份作品，须独立完成、严禁代工抄袭
   - **技术栈**：
     ├─ 工艺设计
     │  ├─ Aspen Plus/ProII（流程模拟）
     │  ├─ HYSYS（动态模拟/气体处理）
     │  └─ 物料/能量衡算与校核
     ├─ 制图与设计
     │  ├─ AutoCAD（工艺流程图/P&ID/设备图）
     │  └─ PDMS/CADWorx/三维工厂设计
     └─ 报告撰写
        ├─ 工艺说明书/设备选型（GB规范）
        └─ 技术经济分析（Excel/Word/PPT答辩）
   - **达标建议**：赛区奖水平：按设计任务书完成全部内容、文档规范齐全；国奖水平：全流程模拟收敛、工艺路线有创新、经济分析完整可信、答辩出色（进入总决赛约100队，全国特等奖约10队、一等奖约30队）

### 第29项：全国大学生地质技能竞赛
- **简称**：地质技能竞赛
- **赛道**：地质/地学
- **周期**：两年一届（时间可能逐年变动）
- **时间线**：校内选拔约3-5月｜全国赛约8月下旬（如2026年第八届8月26-28日，西南石油大学承办）
- **难度**：★★★★
- **适合专业**：地质学、资源勘查工程、勘查技术与工程、地球化学、地理科学等
- **组队**：团体赛，以队为单位参加各赛项（队员构成以当年通知为准）
- **简介**：地学领域级别最高、规模最大的学科竞赛，由中国地质学会主办，覆盖综合应用、野外、标本鉴定全流程地质技能，是地学学生的重要履历。

#### 子赛项
1. **地质技能综合应用**
   - **赛制与规则**：约1天，机房完成；根据组委会提供的地质资料、图件、软件及设备，完成资料分析并按规范制作图件（平面地质图、地质剖面图、综合柱状图等），提交成果与报告
   - **技术栈**：
     ├─ 制图软件（MapGIS/ArcGIS/Global Mapper）
     ├─ 图件规范（剖面图/柱状图/地质报告编写）
     └─ 资料分析（地层对比/构造解析/编图）
   - **达标建议**：图件规范完整、地质解释合理即获高评，各赛项成绩综合评全国一、二、三等奖
2. **野外地质技能**
   - **赛制与规则**：约1天，在组委会选定野外基地完成地质路线观察、现象记录与描述、信手剖面绘制、数据采集及总结报告编写，考察野外工作规范与基本功
   - **技术栈**：
     ├─ 野外工具（地质罗盘/放大镜/手持GPS/地质锤）
     ├─ 实测编录（信手剖面/地质素描/分层描述）
     └─ 野外数据解释与报告编写
   - **达标建议**：观察描述准确、剖面记录规范、总结报告完整
3. **地质标本鉴定**
   - **赛制与规则**：约半天，利用组委会提供的标本、薄片、仪器、工具与试剂，鉴定矿物、岩石、矿石和古生物化石标本，完成实验鉴定报告
   - **技术栈**：
     ├─ 手标本鉴定（矿物物理性质/岩石结构构造）
     ├─ 镜下鉴定（偏光显微镜/光薄片、矿石光片）
     └─ 鉴定报告撰写（定名准确、描述规范）
   - **达标建议**：定名准确率高、报告规范完整
4. **地学知识竞赛（第八届2026年起增设AI与大数据应用赛道）**
   - **赛制与规则**：地学基础理论知识考试与抢答/竞答环节考察基础知识储备；新增赛道考察AI与大数据技术在地学中的应用能力
   - **技术栈**：
     ├─ 地学基础（普通地质/矿物岩石/构造/古生物）
     └─ AI与大数据应用（Python/机器学习在地学数据中的应用）
   - **达标建议**：知识面广、答题准确，AI赛道需完成实际应用任务

### 第35项：全国周培源大学生力学竞赛
- **简称**：周培源力学竞赛
- **赛道**：力学基础
- **周期**：两年一届（单数年完整赛程，时间可能逐年变动）
- **时间线**：报名年初至约3月底（个人赛报名费约120元/人）｜个人赛5月下旬（周日上午8:30-12:00笔试）｜团体赛约7月中旬
- **难度**：★★★★
- **适合专业**：力学、土木、机械、航空航天、车辆、船舶、水利等工科专业
- **组队**：个人赛个人参赛；团体赛每队3-5名学生（比赛时3人上场）+1名带队教师
- **简介**：国内力学领域最高水平、认可度最高的竞赛，教育部高教司委托中国力学学会主办，个人赛成绩是团体赛参赛资格遴选依据。

#### 子赛项
1. **个人赛（闭卷笔试）**
   - **赛制与规则**：闭卷笔试3.5小时（上午8:30-12:00），理论力学与材料力学（含实验内容）综合为一套试卷，考试范围参照基础力学教学大纲；年龄30周岁以下在校专科、本科及研究生均可参赛，以个人成绩排名评定奖项并遴选团体赛高校
   - **技术栈**：
     ├─ 理论力学（静力学/运动学/动力学）
     ├─ 材料力学（强度/刚度/稳定性分析）
     └─ 力学实验基础（实验原理与数据处理）
   - **达标建议**：特等奖前5名，一等奖约5%，二、三等奖按成绩排序；个人赛成绩排名前30所高校获得团体赛独立组队资格
2. **团体赛（理论设计与操作+基础力学实验）**
   - **赛制与规则**：个人赛后举行，由个人赛成绩前30所高校独立组队，另按地区分配原则确定约17所高校代表各省参赛；设"理论设计与操作"与"基础力学实验"两个独立赛道，考察团队协作、创新设计与动手实验能力
   - **技术栈**：
     ├─ 理论设计与操作（创新结构设计/静动力加载试验）
     └─ 基础力学实验（应变电测/材料力学性能测试/光测技术）
   - **达标建议**：进入团体赛即已跻身全国前列；创新设计+实验操作规范+团队配合决定最终名次

### 第44项：全国大学生生命科学竞赛(CULSC)
- **简称**：生科竞赛/CULSC
- **赛道**：生命科学/科研创新
- **周期**：每年一届
- **时间线**：科学探究赛道：上一年8月启动报名｜当年1月报名截止并提交研究综述与实验设计｜5月底上传实验记录与论文｜6-7月网评与省赛｜7月下旬全国决赛；创新创业赛道：1-4月网上申报｜5月网评｜6月省赛｜7月底-8月初全国决赛（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：生物、生物技术、生物工程、医学、药学、农林、食品、环境等
- **组队**：科学探究赛道≤5人/队，创新创业赛道3-5人/队（以当年通知为准）
- **简介**：生命科学领域覆盖面最广的国家级竞赛，分科学探究与创新创业两个赛道，作品周期近一年、重视完整科研过程，保研与科研履历认可度高。

#### 子赛项
1. **科学探究赛道（网评→省赛→全国决赛）**
   - **赛制与规则**：作品制+过程制：上一年8月启动网络报名，当年1月报名截止并上传研究综述与实验设计，5月底上传实验记录、论文等材料；6-7月网络评审并举行省赛（网评成绩决定省级奖项与国赛资格），7月下旬全国决赛现场答辩；评审看重选题创新性、实验设计规范性、过程记录完整性与论文水平
   - **技术栈**：
     ├─ 实验技能（分子克隆/细胞培养/生化分析/组学）
     ├─ 数据分析（SPSS/R/Python/GraphPad Prism）
     └─ 成果写作（研究综述/实验记录/论文/答辩PPT）
   - **达标建议**：省奖水平：完成完整实验并规范记录、论文合格；国奖水平：创新点突出+数据可靠+论文扎实（约700余支队伍入围决赛角逐一、二等奖）
2. **创新创业赛道（网评→省赛→全国决赛）**
   - **赛制与规则**：创新项目与创业项目两类：1-4月网上申报（项目申报书、作品材料），4月资格审查，5月网评，6月省赛，7月底-8月初全国决赛现场答辩；考察项目创新性、可行性与路演表现
   - **技术栈**：
     ├─ 创新项目（技术路线/成果转化/实验验证）
     ├─ 创业项目（商业计划书/市场分析/财务模型）
     └─ 路演答辩（项目PPT+现场演示与问答）
   - **达标建议**：省奖：项目完整、材料规范；国奖：创新性与可行性俱佳、路演表达出色

2. **自选课题类创新作品**

   - **技术栈**：

3. **大学生物理实验讲课比赛**

   - **技术栈**：
     ├─ 教学设计（教案撰写/重难点设计/板书设计）
     ├─ 课件制作（PPT/视频拍摄与剪辑）
     └─ 现场讲授（表达技巧/实验演示操作）
   - **达标建议**：教学设计合理、演示清晰规范、感染力强，按网评+决赛综合评奖

### 第61项：全国大学生化工实验大赛
- **简称**：化工实验大赛
- **赛道**：化工实验/实践
- **周期**：每年一届
- **时间线**：组队报名约5月｜赛区理论选拔约6月下旬（网络考试）｜六大赛区赛7月上中旬｜全国总决赛8月上旬（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：化学工程与工艺、制药工程、应用化学、能源化工等化工类专业
- **组队**：3人/队（含队长，可配指导教师，以当年通知为准）
- **简介**：化工类专业实验技能领域权威赛事（中国化工教育协会主办），覆盖化工原理理论、单元仿真操作、实验操作三大模块，分六大赛区选拔，全国总决赛竞争激烈。
