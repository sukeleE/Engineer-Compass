# 01 电子类竞赛数据

> 来源：全国普通高校大学生竞赛排行榜（中国高等教育学会2023版84项，2025沿用）。时间信息以近年届次为准，标注"约"或"（时间可能逐年变动）"处请以当届官方通知为准。

### 第6项：全国大学生电子设计竞赛
- **简称**：电赛（NUEDC）
- **赛道**：电子机器人
- **周期**：两年一届国赛（奇数年国赛，偶数年省赛，每年均有赛事）
- **时间线**：校内选拔约4-5月｜报名约5-6月｜全国竞赛约8月（奇数年，四天三夜）｜省级竞赛约8月（偶数年）（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：电子信息、自动化、计算机、通信、电气
- **组队**：3人/队
- **简介**：由教育部高教司、工信部人事教育司主办，国内历史最久、影响力最大的电子信息类学科竞赛，国赛获奖对保研、评奖、就业含金量极高；奇数年现场封闭竞赛、偶数年省级竞赛。

#### 子赛项
1. **本科组-电源与电力电子类（如2025年A题：能量回馈变流器负载试验装置、B题：单相有源电力滤波装置）**
   - **赛制与规则**：四天三夜半封闭式竞赛（全国统一命题、分赛区组织），现场公布赛题后从多个题目方向任选一题，硬件制作+设计文档报告；评分看功能指标完成度（基本要求+发挥部分）、电路性能、创新性、报告质量
   - **技术栈**：
     ├─ 硬件设计
     │  ├─ 开关电源拓扑（BUCK/BOOST/LLC/逆变）
     │  ├─ PCB设计（Altium Designer/立创EDA）
     │  └─ 功率器件与磁性元件（MOSFET/IGBT/电感变压器）
     ├─ 嵌入式软件
     │  ├─ STM32/MSPM0 单片机
     │  └─ 闭环控制（PID/SPWM/PLL锁相）
     └─ 仪器仪表使用（示波器/电子负载/功率分析仪）
   - **达标建议**：完成基本要求全部指标（如效率、谐波等基础指标达标）即省奖水平；完成发挥部分全部指标+创新点可冲国奖
2. **本科组-控制类（如2025年C题：基于单目视觉的目标物测量装置、E题：简易自行瞄准装置）**
   - **赛制与规则**：四天三夜现场命题，任选一题；要求实物装置稳定完成指定功能指标（巡迹、视觉测距、激光瞄准等），部分题限定主控平台（如TI MSPM0系列）；评分按指标精度、稳定性和创新性
   - **技术栈**：
     ├─ 视觉与感知
     │  ├─ 单目摄像头（OpenMV/OpenCV图像处理）
     │  └─ 图像特征识别与几何测距算法
     ├─ 运动控制
     │  ├─ 直流电机/舵机云台（PWM驱动）
     │  └─ 循迹传感器（灰度/电磁）
     └─ 嵌入式主控（STM32/MSPM0 + PID控制算法）
   - **达标建议**：稳定完成基本测量/动作指标（如测距范围100-200cm、误差±5%）即省奖水平；达到发挥部分高精度指标（误差≤2%）可冲国奖
3. **本科组-仪器仪表与测量类（如2025年D题：简易以太网双绞线测试仪、G题：电路模型探究装置）**
   - **赛制与规则**：四天三夜现场命题，任选一题；设计测量装置自动完成指定参数测量与显示（线缆连接/衰减、电路建模与辨识、谐波测量等）；评分看测量精度、功能完整度、报告质量
   - **技术栈**：
     ├─ 信号链设计
     │  ├─ 运放/ADC高精度采样电路
     │  └─ 信号调理（滤波/放大/整形）
     ├─ 嵌入式软件
     │  ├─ FFT/谐波分析与建模算法（DSP）
     │  └─ STM32显示与人机交互（LCD/按键）
     └─ 测量仪器（信号源/示波器/网络分析仪）
   - **达标建议**：全部基本测量功能实现即省奖水平；测量误差≤2%且完成发挥部分（如自主学习建模）可冲国奖
4. **本科组-无线通信与射频类（如2025年F题：简易自动接收机、H题：野生动物巡查系统）**
   - **赛制与规则**：四天三夜现场命题，任选一题；设计无线收/发或采集装置（88-108MHz调频/调幅接收、无线巡查数据链路等）；评分按接收灵敏度、功能指标、抗干扰能力
   - **技术栈**：
     ├─ 射频前端
     │  ├─ 射频接收芯片（SI47xx等）与天线设计
     │  └─ 阻抗匹配与射频PCB布线
     ├─ 基带与嵌入式
     │  ├─ STM32解调与信令处理
     │  └─ LoRa/WiFi无线数据链路组网
     └─ 射频仪器（频谱分析仪/矢量网络分析仪）
   - **达标建议**：实现基本接收与数据上报指标即省奖水平；高灵敏度、远距离传输+发挥部分可冲国奖
5. **高职高专组（如2025年I题：非接触式控制盘、J题：超声信标定位系统、K题：自动避障小车）**
   - **赛制与规则**：四天三夜现场命题，题目相对基础，独立命题独立评奖；完成实物功能+设计报告；评分按功能实现度、可靠性、报告
   - **技术栈**：
     ├─ 单片机控制（STM32/51单片机）
     ├─ 传感器（超声/红外/光电/手势识别）
     └─ 电机驱动与简易机械结构
   - **达标建议**：完整实现全部基本功能即省奖水平；实现发挥部分功能可冲国奖

### 第11项：全国大学生智能汽车竞赛
- **简称**：智能车竞赛
- **赛道**：机器人电子
- **周期**：一年一届（2025年为第20届）
- **时间线**：报名约3-5月（校内选拔）｜分赛区竞赛约7月｜全国总决赛约8月（2025年总决赛8月18-20日）（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：自动化、电子信息、计算机、机械、通信
- **组队**：3-5人/队
- **简介**：由中国自动化学会主办，全国规模最大、历史最久的智能车竞速赛事，总决赛在高校铺设赛道现场竞速比拼，自动化与电子信息领域认可度极高；组别逐年调整，需关注当届公告。

#### 子赛项
1. **缩微电磁组**
   - **赛制与规则**：小车沿铺设电磁导线的赛道循迹竞速，现场计时排名，冲出赛道罚时；分区赛排名晋级全国总决赛
   - **技术栈**：
     ├─ 感知
     │  ├─ 电磁传感器（电感+放大+ADC采样）
     │  └─ 信号处理（差分/归一化）
     ├─ 控制
     │  ├─ PID循迹与转向控制
     │  └─ 编码器测速闭环
     └─ 嵌入式主控（STM32/TC264单片机）
   - **达标建议**：稳定完赛（跑完全程不出赛道）即省奖水平；分区赛前列晋级总决赛，总决赛获奖即国奖水平
2. **缩微光电组**
   - **赛制与规则**：采用灰度/红外光电传感器循迹竞速，现场计时排名；分区赛晋级全国总决赛
   - **技术栈**：
     ├─ 光电传感器阵列（灰度/红外循迹）
     ├─ 图像处理（阈值分割/中线提取）
     └─ 电机驱动与PID调速
   - **达标建议**：稳定完赛即省奖水平；高速完赛并晋级总决赛可冲国奖
3. **极速光电组**
   - **赛制与规则**：强调极限速度的光电循迹组，对机械、控制、调参要求最高之一；现场计时排名
   - **技术栈**：
     ├─ 高速光电采样与前瞻处理
     ├─ 运动学模型（预瞄/弯道规划）
     └─ 高响应电机驱动（四轮驱动）
   - **达标建议**：稳定高速完赛（冲线不翻车）即省奖水平；冲刺分区赛前列晋级总决赛可冲国奖
4. **智能视觉组**
   - **赛制与规则**：以摄像头视觉感知赛道与环境（原摄像头组），含视觉元素识别；现场竞速计时排名
   - **技术栈**：
     ├─ 摄像头视觉（OpenMV/OV2640/K210）
     ├─ 图像处理（赛道线检测/目标识别/CNN推理）
     └─ 嵌入式AI（K210/EdgeRunner端侧推理）
   - **达标建议**：摄像头稳定循迹+识别基础元素完赛即省奖水平；识别全部视觉元素并高速完赛可冲国奖
5. **平衡轮腿组**
   - **赛制与规则**：两轮自平衡/轮腿混合结构小车循迹竞速，重点考察平衡控制稳定性；现场计时排名
   - **技术栈**：
     ├─ 姿态传感器（IMU/陀螺仪）
     ├─ 平衡控制算法（串级PID/卡尔曼滤波）
     └─ 无刷电机/舵机轮腿驱动
   - **达标建议**：稳定直立并循迹完赛即省奖水平；全程不倒+高速完赛可冲国奖
6. **双车跟随组**
   - **赛制与规则**：前后两车协同，后车跟随前车行驶完成赛道任务；考察通信与协同控制；现场计时排名
   - **技术栈**：
     ├─ 车车通信（UWB/蓝牙/无线串口）
     ├─ 跟随控制（相对测距/速度协调）
     └─ 双车多机控制（STM32/ESP32组网）
   - **达标建议**：双车稳定跟随完赛即省奖水平；保持车距稳定、高速跟随可冲国奖
7. **独轮信标组**
   - **赛制与规则**：独轮车沿信标灯光引导行驶并依次灭灯，重点考察自平衡+信标定位；现场计时排名
   - **技术栈**：
     ├─ 信标灯检测（光敏/视觉定位）
     ├─ 独轮自平衡控制（飞轮/重心控制）
     └─ 路径规划（信标坐标导航）
   - **达标建议**：稳定平衡并完成基础灭灯任务即省奖水平；全关卡高效完成可冲国奖
8. **极速越野组**
   - **赛制与规则**：户外越野场地高速竞速，GPS/视觉导航，考验整车可靠性与环境适应性；现场计时排名
   - **技术栈**：
     ├─ GPS/RTK定位与航向规划
     ├─ 视觉避障（OpenCV/深度学习）
     └─ 大功率电机与悬挂底盘
   - **达标建议**：户外稳定完赛即省奖水平；无碰撞高速完赛可冲国奖
9. **气垫越野组**
   - **赛制与规则**：气垫船式小车越野竞速，风道驱动无轮行驶；考验气垫控制与操控性；现场计时排名
   - **技术栈**：
     ├─ 气垫风道与风扇驱动（无刷电机）
     ├─ 姿态与推力控制（PD算法）
     └─ 无线遥控/自主循迹切换
   - **达标建议**：气垫稳定行驶完赛即省奖水平；平稳高速控制可冲国奖
10. **完全模型组**
    - **赛制与规则**：功能最全的高性能模型车组，综合视觉、电磁、里程计等完成复杂赛道；考察综合工程能力；现场计时排名
    - **技术栈**：
      ├─ 多源融合感知（摄像头+电磁+编码器）
      ├─ 复杂路径规划（地图构建/最优路径）
      └─ 高性能整车控制（IMU+闭环调速）
    - **达标建议**：综合感知稳定完赛即省奖水平；全要素高精度完成可冲国奖
11. **AI创意组（智慧配送/智慧医疗/智慧生活）**
    - **赛制与规则**：开放命题的AI应用创意赛，分区赛作品评审+全国总决赛现场演示答辩；强调场景创新与完成度
    - **技术栈**：
      ├─ AI应用（视觉识别/大模型/ROS机器人）
      ├─ 智能车平台（ROS2+激光雷达/深度相机）
      └─ 云端部署（边缘计算/模型推理优化）
    - **达标建议**：作品功能完整、演示流畅即省级奖水平；技术创新+落地性强可冲国奖

### 第30项：全国大学生光电设计竞赛
- **简称**：光电赛
- **赛道**：光电工程
- **周期**：一年一届（2025年为第13届）
- **时间线**：报名约5-6月｜区赛约7月｜全国总决赛约8月（2025年总决赛8月19-22日）（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：光电信息科学与工程、物理、电子信息、仪器仪表、自动化
- **组队**：3人/队（研究生不多于1名且不得任队长，指导教师≤2名）
- **简介**：由中国光学学会主办，光电领域规模最大、认可度最高的全国性学科竞赛，设实物竞赛主赛道与光学设计赛道；区赛晋级国赛制，总决赛现场比拼。

#### 子赛项
1. **实物竞赛主赛道-智能车的激光对抗（赛题1）**
   - **赛制与规则**：分七大赛区举办区赛（报名+材料评审+区赛决赛），优胜队晋级全国总决赛；现场智能车避雷行驶+识别对方车体并激光打击，光电竞技；评分看任务完成度与用时
   - **技术栈**：
     ├─ 视觉识别（摄像头/OpenCV目标检测）
     ├─ 激光打击云台（舵机二维瞄准）
     └─ 智能车底盘（STM32循迹+避障控制）
   - **达标建议**：完整参赛并完成基础任务即省奖（区赛奖）水平；区赛前列晋级国赛，国赛获奖即国奖水平
2. **实物竞赛主赛道-大深径比微孔参数的光学无损测量（赛题2）**
   - **赛制与规则**：区赛晋级国赛制；设计测量装置无损测量直径<0.3mm、深径比>3微孔的深径比等参数；评分看测量精度与方案创新性
   - **技术栈**：
     ├─ 光学成像（显微物镜/光学显微系统）
     ├─ 图像处理（边缘检测/三维重构）
     └─ 精密机械（位移台/对焦机构）
   - **达标建议**：完成基础测量指标（如孔径/深径比测量误差达标）即省奖水平；精度领先+方案新颖可冲国奖
3. **光学设计赛道（赛题二选一：水浸物镜设计/微单镜头设计）**
   - **赛制与规则**：不设区赛，全国统一竞赛，分初赛（提交设计报告）与复赛（线上答辩/测评）两阶段；用光学设计软件完成镜头设计，考察像差优化与工程可行性
   - **技术栈**：
     ├─ 光学设计软件（ZEMAX/OpticStudio/CODE V）
     ├─ 像差分析与优化（MTF/点列图）
     └─ 镜头结构设计与公差分析（CAD）
   - **达标建议**：设计指标全部达标（如MTF满足要求）即省级奖水平；像质优异+量产可行性论证充分可冲国奖
4. **创意赛道（开放命题，部分届次设置）**
   - **赛制与规则**：开放式光电创意作品路演与答辩，部分高校先校内选拔再推省赛；评审看创新性、完成度、展示效果
   - **技术栈**：
     ├─ 光电应用创意（激光/显示/传感方案）
     ├─ 样机搭建（Arduino/STM32快速原型）
     └─ 路演展示（方案文档/实物演示）
   - **达标建议**：作品完整可实现即省奖水平；创新点突出+演示效果好可冲国奖

### 第31项：全国大学生集成电路创新创业大赛
- **简称**：集创赛
- **赛道**：集成电路
- **周期**：一年一届（2025年为第9届）
- **时间线**：报名约1-3月｜中期报告约4月｜初赛作品约5-6月｜分赛区决赛约7月｜全国总决赛约8月（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：微电子科学与工程、集成电路设计与集成系统、电子科学与技术、电子信息
- **组队**：1-3人/队（指导教师1-2名）
- **简介**：由工信部人才交流中心主办，集成电路领域规模最大、企业参与度最高的国家级赛事，主赛项设4大技术方向、11个赛道、25个企业杯赛，另设职业技能赛项；企业命题贴近产业，获奖对求职、保研认可度高。

#### 子赛项
1. **射频与高速电路赛道（如射频收发/高速接口杯赛）**
   - **赛制与规则**：主赛项企业杯赛命题，报名→中期报告→初赛作品线上评审→分赛区决赛→全国总决赛现场答辩评审；分A组（全本科生）/B组（含研究生），部分杯赛仅限A组
   - **技术栈**：
     ├─ 射频电路设计（Cadence Virtuoso/ADS）

### 第66项：全国大学生信息安全与对抗技术竞赛
- **简称**：ISCC
- **赛道**：网络安全
- **周期**：一年一届（2025年为第22届）
- **时间线**：线上挑战赛（破阵夺旗/无限擂台/数据安全）报名约4月底-5月初、比赛约5月｜博弈对抗/创新作品/智能安全赛约4-10月（校级→区域→全国，智能安全赛总决赛约10月）（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：网络空间安全、计算机科学与技术、密码学、软件工程
- **组队**：3人/队（须来自同一院校，每人限报1队）
- **简介**：由北京理工大学与中国兵工学会联合主办，国内创办最早、影响力最大的信息安全竞赛之一，设破阵夺旗、无限擂台、数据安全、博弈对抗、创新作品、智能安全6个赛项；大学生赛区实行校赛→区域赛→全国总决赛三级赛制，研究生/中小学生直接进入总决赛独立评奖。

#### 子赛项
1. **破阵夺旗赛（CTF：CHOICE/WEB/REVERSE/PWN/MISC/MOBILE）**
   - **赛制与规则**：线上解flag竞速积分赛，校赛→区域赛（多省组成区域）→全国总决赛三级赛制；校赛每校限推20支队伍，区域赛一、二等奖按不超50%比例推荐国赛；积分排名决定晋级与奖项
   - **技术栈**：
     ├─ Web渗透（SQL注入/XSS/文件上传/反序列化）
     ├─ 逆向工程（IDA/Ghidra/脱壳与算法还原）
     ├─ Pwn二进制利用（栈溢出/堆利用/格式化串）
     └─ 杂项与取证（MISC/流量分析/隐写/移动逆向）
   - **达标建议**：能解出基础入门题（Web/杂项签到题）即校赛出线水平；系统掌握2-3个方向并进入区域赛获奖，区域赛一二等奖晋级国赛即国奖水平
2. **无限擂台赛**
   - **赛制与规则**：线上打擂积分赛：解题获得打擂资格，可提交原创题目攻擂；5月上旬开放，全程在线积分
   - **技术栈**：
     ├─ 综合CTF能力（多方向解题）
     ├─ 原创题目设计（题目编写/环境搭建）
     └─ 擂主防守（防被解/反思路）
   - **达标建议**：累计积分进入榜单前列即获奖水平；攻守平衡、原创题目质量高可获高名次
3. **数据安全赛**
   - **赛制与规则**：线上算法赛：用机器学习/深度学习对给定数据问题建模，提交测试集预测结果，按精度指标排名
   - **技术栈**：
     ├─ Python数据分析（Pandas/NumPy）
     ├─ 机器学习（Sklearn/XGBoost/深度学习框架）
     └─ 特征工程与模型调优
   - **达标建议**：基线模型跑通并提交有效结果即参与获奖水平；特征工程+模型精度领先可获高名次
4. **博弈对抗赛（近真环境攻防对抗）**
   - **赛制与规则**：线下/半线下实时攻防对抗（阵地夺旗、占领高地等模式），周期性（4-10月）组织，按对抗成绩评奖
   - **技术栈**：
     ├─ 网络攻防（渗透/加固/提权）
     ├─ 主机与服务器安全（漏洞利用/防护策略）
     └─ 攻防靶场环境（红蓝对抗/应急响应）
   - **达标建议**：攻防操作规范、能完成基础夺旗任务即获奖水平；攻防兼备、策略性强可获高名次
5. **创新作品赛（自主命题安全作品）**
   - **赛制与规则**：开放式自主命题，提交安全领域原创作品（代码+文档+演示）并评审答辩；周期性组织
   - **技术栈**：
     ├─ 安全产品开发（Python/C++/Go安全工具）
     ├─ 漏洞研究（代码审计/漏洞挖掘/利用链）
     └─ 安全应用（密码学/隐私保护/区块链安全）
   - **达标建议**：作品功能完整、可复现演示即获奖水平；技术创新+实用性突出可获高名次

   - **技术栈**：

   - **达标建议**：作品或方案完整落地即区域奖水平；区域赛晋级全国决赛并获奖即国奖水平
