# 06 创新创业类竞赛数据（全国普通高校大学生竞赛排行榜·高教学会2023版84项，2025沿用）

> 创新创业类竞赛以商业计划、路演表达、产品原型、调研报告能力为核心，全部数据按 competition / competition_process / tech_stack 三表结构整理，可直接落库。

### 第1项：中国国际大学生创新大赛
- **简称**：互联网+/国创大赛
- **赛道**：综合
- **周期**：每年一届
- **时间线**：报名约4-5月｜校赛约5-6月｜省赛约6-8月｜国赛约10月（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：所有专业
- **组队**：3-15人/队（可跨校、跨专业、跨年级，每校入选国赛总决赛限额5项以内）
- **简介**：教育部等部委主办的最高规格大学生创新创业赛事，排行榜第1位，全国高校参与面最广（2025年全球161个国家和地区、5673所学校、619万个项目参赛），国赛金奖保研加分权重最高，含金量、认可度均居各类竞赛之首。

#### 子赛项
1. **高教主赛道（含国际参赛项目）**
   - **赛制与规则**：项目路演答辩制，分本科生组、研究生组，均设创意组/创业组；流程为校级初赛→省级复赛（网评+现场赛）→全国总决赛（金奖争夺赛、冠军争夺赛）；评审指标看创新性、商业性、团队、带动就业（社会价值）；2025年起项目类型覆盖"四新"（新工科/新医科/新农科/新文科）+"人工智能+"及低空经济、生物技术、量子科技、新能源、新材料共10类
   - **技术栈**：
     ├─ 项目文档
     │  ├─ 商业计划书（BP）
     │  └─ 财务测算与市场分析
     ├─ 路演表达
     │  ├─ PPT制作与视觉设计
     │  └─ 演讲与答辩技巧
     ├─ 产品原型
     │  ├─ 小程序/APP/网站
     │  └─ 硬件原型或实物模型
     └─ 商业模式
        ├─ 商业模式画布
        └─ 知识产权布局（专利/软著）
   - **达标建议**：校奖：有完整BP+路演稿，通过校赛网评即可；省奖：具备可演示原型+真实运营数据（营业额/用户数/订单），路演熟练；国赛金银奖：需专利软著等硬成果、落地运营数据、媒体报道、营收流水等支撑，为全校重点培育项目
2. **"青年红色筑梦之旅"赛道**
   - **赛制与规则**：设公益组/创意组/创业组，面向精准扶贫、乡村振兴、城乡社区发展，要求项目在推进农业农村和城乡社区经济社会发展方面有创新性、实效性、可持续性；须先参加"青年红色筑梦之旅"实践活动（实地调研并提交活动记录），再经网评+现场路演评审
   - **技术栈**：
     ├─ 实践调研
     │  ├─ 乡村/社区实地走访
     │  └─ 调研报告与数据采集
     ├─ 项目材料
     │  ├─ 商业计划书（BP）
     │  └─ 实践活动纪实（照片/视频）
     ├─ 路演表达
     │  ├─ PPT与视频制作
     │  └─ 故事化演讲与答辩
     └─ 模式设计
        ├─ 公益模式设计
        └─ 可持续运营测算
   - **达标建议**：校奖：完成实践活动+BP；省奖：有落地试点（帮扶农户数/带动就业数）等实效数据；国赛金奖：乡村振兴实效显著、获政府或媒体认可、形成可复制模式
3. **职教赛道**
   - **赛制与规则**：面向职业院校学生，设创意组/创业组，强调技术技能型创新与产教融合，评审注重实际应用能力；流程同高教主赛道（校赛→省赛→国赛网评+现场路演），每校入选国赛项目不超过3个
   - **技术栈**：
     ├─ 技能原型
     │  ├─ 作品实物/样机
     │  └─ 工艺改进方案
     ├─ 项目文档
     │  ├─ 商业计划书（BP）
     │  └─ 技能应用说明
     ├─ 路演表达
     │  ├─ PPT制作
     │  └─ 现场实操展示与答辩
     └─ 产教结合
        ├─ 校企合作证明
        └─ 岗位技能落地验证
   - **达标建议**：校奖：有作品原型+BP；省奖：作品可现场演示、有企业试用或订单；国赛金银奖：技术技能创新性强、与企业深度合作并形成成果转化
4. **产业命题赛道**
   - **赛制与规则**：坚持"产业出题、高校揭榜、学生答题"，设企业命题组和成果转化组（2025年新增成果转化组、区域特色产业组）；企业发布真实命题，团队针对命题提交解决方案（方案书+视频），经网评+现场答辩；同一命题每校入围国赛不超过3项
   - **技术栈**：
     ├─ 方案文档
     │  ├─ 命题解决方案书
     │  └─ 技术路线图
     ├─ 技术实现
     │  ├─ 原型开发/算法实现
     │  └─ 测试验证报告
     ├─ 演示材料
     │  ├─ 解决方案PPT
     │  └─ 演示视频/系统截图
     └─ 对接能力
        ├─ 企业需求理解
        └─ 路演答辩
   - **达标建议**：校奖：提交完整方案书；省奖：方案技术可行、有原型验证；国赛金银奖：方案被命题企业认可采纳、具备落地转化可行性
5. **萌芽赛道**
   - **赛制与规则**：面向普通高中学生，考察创新潜质与创意新颖性，以创意方案/作品实物形式参赛，评出创新潜力奖（2025年20项）；发挥高等教育对中学创新教育的引领作用，为大赛储备"种子"项目
   - **技术栈**：
     ├─ 创意表达
     │  ├─ 创意方案书
     │  └─ 作品实物/模型
     ├─ 展示材料
     │  ├─ 展板/PPT
     │  └─ 短视频
     └─ 创新思维
        ├─ 问题发现与构思
        └─ 原型验证
   - **达标建议**：入围总决赛即获认可，评"创新潜力奖"（每届约20项）；要求创意新颖、有实物或雏形支撑

### 第2项："挑战杯"全国大学生课外学术科技作品竞赛
- **简称**：大挑
- **赛道**：综合
- **周期**：两年一届（奇数年举办，如2023年第十八届、2025年第十九届）
- **时间线**：报名约3-4月｜校赛约4月｜省赛约5-6月｜国赛终审决赛约10-11月（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：所有专业（自然科学论文适合理工科，社科调查报告适合文法经管类，科技发明制作适合工科）
- **组队**：个人或集体作品参赛（集体作品一般2-8人，以当届章程为准）；每人限报1件作品，作品须为近两年完成的原创成果
- **简介**：共青团中央、中国科协、教育部、全国学联主办，与"小挑"并称"挑战杯"，排行榜第2位；学术科技成果含金量极高，国赛获奖在保研、评奖中权重极大，被誉为"大学生科技创新的奥林匹克"。

#### 子赛项
1. **主体赛——自然科学类学术论文**
   - **赛制与规则**：提交原创学术论文参赛，仅限本专科生参加；选题须紧扣前沿科学问题，论文字数一般不超过8000字；校赛→省赛→全国终审决赛，评审看科学性、先进性、现实意义；全国终审为书面评审+现场问辩
   - **技术栈**：
     ├─ 科研方法
     │  ├─ 文献调研与选题
     │  └─ 实验/数据分析
     ├─ 论文写作
     │  ├─ 学术论文撰写
     │  └─ 图表与引用规范
     └─ 学术表达
        ├─ 答辩PPT
        └─ 现场问辩
   - **达标建议**：校奖：论文结构完整、数据可靠；省奖：创新点明确、达到公开发表水平；国赛获奖：研究具原创性与先进性，多为已发表/已录用高水平论文
2. **主体赛——哲学社会科学类社会调查报告**
   - **赛制与规则**：提交社会调查报告参赛，调查报告一般不超过15000字；选题聚焦经济社会发展现实问题，须有实地调查过程与一手数据；全国终审为书面评审+现场问辩，评审看选题价值、调查规范性、分析深度、对策可行性
   - **技术栈**：
     ├─ 社会调查
     │  ├─ 问卷设计与抽样
     │  └─ 访谈/实地调研
     ├─ 数据分析
     │  ├─ 统计分析与建模
     │  └─ 数据可视化
     ├─ 报告写作
     │  ├─ 调研报告撰写
     │  └─ 政策建议提炼
     └─ 答辩表达
        ├─ 汇报PPT
        └─ 现场问辩
   - **达标建议**：校奖：完成规范调查+报告；省奖：样本量充足、方法规范、对策有参考价值；国赛获奖：选题反映重大现实问题，形成可被采纳的政策建议
3. **主体赛——科技发明制作**
   - **赛制与规则**：提交科技发明实物作品参赛，分A类（科技含量较高、制作投入较大的作品）和B类（投入较少、为生产技术或社会生活带来便利的小发明小制作）；全国终审决赛设现场展示环节，评委实地考察实物并问辩；评审看科学性、先进性、实用性、经济效益或社会效益
   - **技术栈**：
     ├─ 技术实现
     │  ├─ 机械/电子/软件设计
     │  └─ 样机制作与调试
     ├─ 技术文档
     │  ├─ 作品说明书
     │  └─ 技术报告
     ├─ 展示表达
     │  ├─ 实物现场展示
     │  └─ 答辩PPT与演示视频
     └─ 成果转化
        ├─ 专利申报
        └─ 应用证明/检测报告
   - **达标建议**：校奖：有可运行的样机+说明书；省奖：作品完成度高、有应用或试用场景；国赛获奖：具备创新性硬技术、专利支撑、实际应用或产业转化前景
4. **"揭榜挂帅"专项赛**
   - **赛制与规则**：以"政企发榜、竞争揭榜、开榜签约"方式开展，由政府、企业、科研机构发榜提出关键技术问题，学生团队揭榜答题；与主体赛分开评审，聚焦科技发展前沿和关键核心技术（如人工智能、芯片、新材料等），获奖项目可与发榜单位对接落地
   - **技术栈**：
     ├─ 技术攻关
     │  ├─ 命题技术方案
     │  └─ 核心算法/技术实现
     ├─ 材料准备
     │  ├─ 揭榜方案书
     │  └─ 技术验证报告
     └─ 成果对接
        ├─ 答辩汇报
        └─ 与企业签约落地
   - **达标建议**：省赛获奖相对主体赛竞争较小，是"曲线获奖"的好赛道；国赛获奖须方案实际解决发榜难题、技术指标达标
5. **红色专项活动**
   - **赛制与规则**：配套活动，以团队或个人形式赴红色教育基地、革命老区等开展实践，形成实践成果；须提交申报书+短视频（5分钟以内）+调研报告（5000-10000字）；以省为单位评审推报，评审看实践深度、成果质量、育人实效
   - **技术栈**：
     ├─ 实践策划
     │  ├─ 红色调研路线与方案
     │  └─ 访谈与资料采集
     ├─ 成果制作
     │  ├─ 调研报告撰写
     │  └─ 短视频剪辑
     └─ 展示表达
        ├─ 成果PPT
        └─ 活动总结申报书
   - **达标建议**：省级获奖比例相对较高，认真完成实践+规范报告+有感染力的视频即有望省奖；国赛获奖需实践成果获当地认可、传播影响力大
6. **"黑科技"展示活动**
   - **赛制与规则**：配套活动，鼓励学生展示充满想象力、创造力的新思路、新方法、新技术，以实物、技术、概念等形式参赛（如前沿科技、未来设计、颠覆性创意）；评审看创意新颖性、科技感、展示效果
   - **技术栈**：
     ├─ 创意开发
     │  ├─ 前沿概念设计
     │  └─ 原型/模型制作
     ├─ 展示包装
     │  ├─ 展板与宣传海报
     │  └─ 展示视频
     └─ 概念表达
        ├─ 创意阐述文案
        └─ 现场讲解
   - **达标建议**：突出"黑科技"视觉冲击与想象力，实物+视频双管齐下；获奖看重创意独特性与展示完成度
7. **"人工智能+"专项赛（第十九届起增设）**
   - **赛制与规则**：面向人工智能技术与各行业场景融合应用的专项赛，设发榜或自由选题形式，聚焦"人工智能+"赋能产业、教育、医疗、治理等领域，与"揭榜挂帅"并行评审（以当届章程为准）
   - **技术栈**：
     ├─ AI技术实现
     │  ├─ 模型训练与调优
     │  └─ 应用系统开发
     ├─ 场景应用
     │  ├─ 行业场景方案
     │  └─ 数据与效果验证
     └─ 成果展示
        ├─ 演示系统/视频
        └─ 答辩汇报
   - **达标建议**：AI应用落地完整、效果可量化即具竞争力；本赛道为新增赛道，信息差优势明显

### 第3项："挑战杯"中国大学生创业计划大赛
- **简称**：小挑
- **赛道**：创新创业
- **周期**：两年一届（偶数年举办，与大挑错年，如2024年第十四届、2026年第十五届）
- **时间线**：报名约12-2月｜校赛约3-4月｜省赛约4-6月｜国赛约7-8月（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：所有专业
- **组队**：以团队参赛，团队人数原则上不超过15人（一般建议7-10人），指导教师不超过5人；博士研究生仅可作成员（不超总数30%且不得任负责人），每人限报1个项目，鼓励跨学科、跨专业组队
- **简介**：共青团中央等主办、与"大挑"并称"挑战杯"的姊妹赛事，排行榜第3位；聚焦创业计划与落地实践，国赛金银奖在保研、评奖中权重极高，与互联网+同属创新创业类第一梯队。

#### 子赛项
1. **科技创新和未来产业组**
   - **赛制与规则**：围绕创新驱动发展战略，在量子技术、元宇宙、智能制造、信息技术、大数据、人工智能、生命科学、新材料、军民融合等领域设计创业项目；每个项目只能选择一个组别参赛；赛制为商业计划书评审+路演答辩（校赛→省赛→国赛），评审看社会价值、实践过程、创新意义、发展前景、团队协作
   - **技术栈**：
     ├─ 项目文档
     │  ├─ 商业计划书（BP）
     │  └─ 财务测算与融资规划
     ├─ 技术壁垒
     │  ├─ 核心技术与知识产权
     │  └─ 产品/样机原型
     ├─ 路演表达
     │  ├─ 路演PPT
     │  └─ 演讲与答辩
     └─ 市场验证
        ├─ 市场调研与竞品分析
        └─ 订单/用户数据
   - **达标建议**：校奖：BP完整规范；省奖：有产品原型+初步市场验证；国赛金银奖：技术壁垒真实、有营收流水/融资/专利等硬指标，路演表现顶尖
2. **乡村振兴和农业农村现代化组**
   - **赛制与规则**：围绕乡村振兴战略，在农林牧渔、电子商务、乡村旅游、城乡融合等领域设计创业项目；强调实践导向，优先考察项目落地乡村的实效；评审看重带动就业、助农增收等社会价值
   - **技术栈**：
     ├─ 项目设计
     │  ├─ 商业计划书（BP）
     │  └─ 助农模式设计
     ├─ 实践运营
     │  ├─ 乡村试点落地
     │  └─ 带农增收数据
     ├─ 路演表达
     │  ├─ 路演PPT
     │  └─ 实践故事化呈现
     └─ 模式验证
        ├─ 成本收益测算
