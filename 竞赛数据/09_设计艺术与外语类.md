# 09 设计艺术与外语类竞赛数据

> 数据来源：全国普通高校大学生竞赛排行榜（高教学会2023版84项，2025沿用）。时间线按近年常规安排标注"约"，实际时间可能逐年变动，以当年官网通知为准。本文件数据将导入 SQLite（competition / competition_process / tech_stack 表），用于弹窗展示、ECharts 技术栈树与时间轴排布。

### 第10项：全国大学生广告艺术大赛
- **简称**：大广赛
- **赛道**：设计艺术
- **周期**：每年一届
- **时间线**：命题发布约3月｜作品提交截止约6月｜评审约7月｜颁奖约11月（时间可能逐年变动）
- **难度**：★★★
- **适合专业**：广告学、视觉传达、设计学、美术、传媒、市场营销
- **组队**：1-5人（部分类别可单人，集体创作作者不超过5人）
- **简介**：教育部高等教育司指导、中国高等教育学会广告教育专业委员会主办的全国性A类广告赛事，是中国规模最大、覆盖高校最广的大学生广告创意大赛，命题来自知名企业真实需求，获奖作品企业认可度高，是广告、设计专业保研与求职的重要加分项。赛制为校赛-省赛-国赛逐级推优，第16届设11个作品类别。

#### 子赛项
1. **平面类**（平面广告、产品与包装、IP与创意周边）
   - **赛制与规则**：按企业命题创作平面广告/包装/IP设计，网上提交作品，专家网评打分，校赛推优后进入省赛、国赛。
   - **能力与工具要求**：
     ├─ 创意设计（构图/配色/版式/IP造型）
     ├─ 工具软件（Photoshop/Illustrator/InDesign）
     └─ 命题理解与品牌调性把控
   - **达标建议**：省赛获奖需主题切题、执行完成度高；国赛获奖需创意差异化明显、达到可商业发布的专业水准（企业视觉规范应用到位）。
2. **视频类**（影视广告、微电影广告、短视频）
   - **赛制与规则**：按命题创作影视广告（15-30秒）、微电影（1-3分钟）或短视频，线上提交作品与拍摄花絮，专家评审。
   - **能力与工具要求**：
     ├─ 剧本创意与分镜设计
     ├─ 拍摄与剪辑（Premiere/剪映/After Effects）
     └─ 视听语言与音效包装
   - **达标建议**：省赛获奖需叙事完整、声画质量过关；国赛获奖需创意贴近真实广告传播场景（评审含广告业界专家）。
3. **动画类**
   - **赛制与规则**：命题动画广告（二维/三维/定格均可），时长一般30秒以内，网评打分。
   - **能力与工具要求**：
     ├─ 动画运动规律与角色设计
     ├─ 工具软件（After Effects/An/Blender/C4D）
     └─ 节奏把控与转场设计
   - **达标建议**：省赛获奖需动画流畅、主题明确；国赛获奖需造型风格、运动表现与创意叙事突出。
4. **互动类**（移动端H5、场景互动）
   - **赛制与规则**：命题H5互动广告或线下场景互动装置方案，H5需提交可体验链接/源码，专家评审交互体验与创意。
   - **能力与工具要求**：
     ├─ 交互逻辑与用户路径设计
     ├─ 工具软件（iH5/墨刀/Unity/Web前端技术）
     └─ 界面视觉与动效设计
   - **达标建议**：省赛获奖需交互闭环完整、可体验；国赛获奖需体验新颖、传播裂变性强。
5. **广播类**（广播广告、音频节目）
   - **赛制与规则**：命题广播广告/音频类节目（含歌曲、情景剧等），提交音频文件，专家评审。
   - **能力与工具要求**：
     ├─ 广告文案写作（广告语/旁白脚本）
     ├─ 工具软件（Audition/Cubase/手机录音）
     └─ 声音表现力与配乐音效设计
   - **达标建议**：省赛获奖需文案有记忆点、制作干净；国赛获奖需创意独特、听觉传播力强。
6. **策划案类**（广告策划、营销策划）
   - **赛制与规则**：针对命题企业营销目标撰写策划案（市场分析、创意策略、媒介计划、预算），提交PDF方案，部分届别国赛设现场提案答辩环节。
   - **能力与工具要求**：
     ├─ 市场分析与策略策划能力
     ├─ 工具软件（PowerPoint/Word/XMind/数据图表）
     └─ 提案表达与逻辑呈现
   - **达标建议**：省赛获奖需结构完整、逻辑清晰；国赛获奖需策略洞察深入、方案可落地（评审含企业市场负责人）。
7. **文案类**（广告语、长文案、创意脚本）
   - **赛制与规则**：命题广告语、长文案、创意脚本创作，纯文字作品网评。
   - **能力与工具要求**：
     ├─ 中文功底与文字创意
     └─ 品牌语感与消费者洞察
   - **达标建议**：省赛获奖需语言凝练、扣题；国赛获奖需金句突出、传播性强。
8. **UI类**（移动端、PC端界面设计）
   - **赛制与规则**：命题界面/交互设计，提交效果图与交互说明，网评打分。
   - **能力与工具要求**：
     ├─ 界面设计规范（栅格/字体/色彩/组件）
     ├─ 工具软件（Figma/Sketch/Axure）
     └─ 交互逻辑与视觉一致性
   - **达标建议**：省赛获奖需视觉规范、可用性强；国赛获奖需设计语言统一且具创新性。
9. **科技类**（生成式AI设计）
   - **赛制与规则**：使用指定生成式AI工具（如讯飞星火）按命题创作设计作品，需提交创作过程说明，评审AI应用能力与创意。
   - **能力与工具要求**：
     ├─ AI提示词工程与生成工具运用
     ├─ 后期精修（Photoshop）
     └─ 创意概念与AI伦理合规
   - **达标建议**：省赛获奖需按要求完成AI创作；国赛获奖需人机协同创意突出、作品可直接落地。
10. **营销创客类**（电商短视频、网络直播）
    - **赛制与规则**：电商短视频制作或网络直播实战带货命题，提交视频/直播数据，评审内容创意与销售转化。
    - **能力与工具要求**：
      ├─ 短视频运营与直播话术
      ├─ 工具软件（剪映/直播工具/数据后台）
      └─ 商品理解与流量转化
    - **达标建议**：省赛获奖需作品完整、数据真实；国赛获奖需内容与转化双优。
11. **公益类**
    - **赛制与规则**：围绕公益命题（如全民阅读等）创作，可从平面、视频、动画、互动等类别中任选形式参赛。
    - **能力与工具要求**：
      ├─ 公益主题洞察与创意表达
      ├─ 工具软件（视所选类别：Photoshop/AI/Premiere等）
      └─ 情感共鸣与传播价值
    - **达标建议**：省赛获奖需紧扣公益主题；国赛获奖需情感打动力强、传播价值高。

### 第15项："外研社·国才杯""理解当代中国"全国大学生外语能力大赛
- **简称**：外研社·国才杯（国才杯）
- **赛道**：外语
- **周期**：每年一届
- **时间线**：校赛约9-10月｜省赛约10-11月｜国赛约11-12月（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：英语、翻译、国际传播、多语种外语专业（英语组面向全体在校生，不限专业）
- **组队**：个人赛（短视频赛项可组队）
- **简介**：北京外国语大学主办、外语教学与研究出版社承办的全国最高水平大学生外语赛事，入选教育部竞赛排行榜A类，覆盖英语、俄、德、法、西、阿、日、意、葡、韩及国际中文共11个语种。赛题源于《习近平谈治国理政》与《理解当代中国》系列教材，是外语专业保研与就业含金量最高的竞赛之一。采用校赛-省赛-国赛三级赛制，英语组赛项逐年微调（2023年设演讲/写作/阅读/翻译分赛项，2024年起整合为综合能力赛并新增短视频，口译2026年起隔年举办）。

#### 子赛项
1. **国际传播综合能力赛项**（英语组核心赛项，整合阅读/写作/翻译/演讲）
   - **赛制与规则**：校赛、省赛、国赛均以"读以博闻""读以明理""读以启思""译以通意""写以言志"等模块综合考查读写译说能力，含术语翻译选择、文本阅读、图表信息、逻辑推理、中译英、议论文写作等题型。
   - **能力与工具要求**：
     ├─ 英语综合运用（读写译说）
     ├─ 时政话语与中华思想文化术语表达
     └─ 逻辑思辨与限时作答
   - **达标建议**：省赛获奖需综合测试成绩居全省前列；国赛获奖需对当代中国话语体系表达精准、临场作答稳定。
2. **演讲赛项**
   - **赛制与规则**：定题演讲（3分钟）+即兴演讲（3分钟）+回答问题，省赛分两轮淘汰（可含论辩形式），个人参赛。
   - **能力与工具要求**：
     ├─ 英语口语与语音语调
     ├─ 临场思辨与即兴组织语言
     └─ 演讲台风与情感张力
   - **达标建议**：省赛获奖需定题与即兴两轮表现稳定；国赛获奖需内容深度、语言质量与现场感染力兼备。
3. **笔译赛项**
   - **赛制与规则**：全国统一线上初赛（客观题+英译汉+汉译英各1篇），省赛/国赛考查时政文献语篇翻译、文学选篇翻译、译后编辑、新闻编译及术语阐释。
   - **能力与工具要求**：
     ├─ 汉英双语功底与术语翻译
     ├─ 时政文献与典籍翻译规范
     └─ 译后编辑与信息检索
   - **达标建议**：省赛获奖需线上初赛高分入围；国赛获奖需译文准确地道、契合官方话语体系。
4. **口译赛项**
   - **赛制与规则**：考查视译、交替传译（主旨口译/会议口译/对话口译），2026年起隔年举办（下一次为2027年）。
   - **能力与工具要求**：
     ├─ 听力速记与视译能力
     ├─ 中英双向口译与临场应变
     └─ 知识面与时政储备
   - **达标建议**：省赛获奖需交传基本流畅、无重大失误；国赛获奖需信息完整、译语质量高、抗压性强。
5. **短视频赛项**（2024年新增）
   - **赛制与规则**：围绕主题创作英语短视频（约2-5分钟），可组队，提交视频与文稿，评审内容、语言与传播力。
   - **能力与工具要求**：
     ├─ 脚本创作与英语配音
     ├─ 工具软件（剪映/Premiere）
     └─ 视觉叙事与国际传播视角
   - **达标建议**：省赛获奖需主题明确、制作规范；国赛获奖需叙事精巧、思想性与传播力俱佳。
6. **多语种组赛项**
   - **赛制与规则**：面向俄/德/法/西/阿/日/意/葡/韩9个语种，不设分赛项，综合考查阅读、写作、演讲、笔译、口译等能力，三级赛制。
   - **能力与工具要求**：
     ├─ 目标语种综合运用能力
     ├─ 当代中国主题语料积累
     └─ 演讲与翻译综合素养
   - **达标建议**：省赛获奖需综合测试居全省前列；国赛获奖需各环节全面均衡、表现出色。
7. **国际中文组赛项**
   - **赛制与规则**：面向国际学生的中文能力赛事，考查中文综合运用与中华文化理解表达，三级赛制。
   - **能力与工具要求**：
     ├─ 中文听读写说能力
     └─ 中华文化理解与跨文化表达
   - **达标建议**：省赛获奖需中文水平测试突出；国赛获奖需文化阐释深度与表达感染力兼备。

### 第16项：两岸新锐设计竞赛·华灿奖
- **简称**：华灿奖
- **赛道**：设计艺术
- **周期**：每年一届
- **时间线**：报名约7月｜创意赛道提交截止约9月｜定向主题截止约11月｜校赛/赛区赛约10-11月｜总赛约11-12月（时间可能逐年变动）
- **难度**：★★★
- **适合专业**：视觉传达、产品设计、数字媒体、环境设计、文创设计、元宇宙/数字艺术
- **组队**：1-5人（1名第一作者+不超过4名成员，指导教师不超过2人）
- **简介**：中国高等教育学会主办的两岸新锐设计赛事，面向海峡两岸暨港澳高校师生、青年设计师及海外华人（45岁以下），突出两岸文化交流与设计成果转化，入选教育部竞赛排行榜。设创意赛道（6大组别）与定向主题赛道，总赛含现场路演环节，产业化转化是重要评分维度。

#### 子赛项
1. **元宇宙设计**
   - **赛制与规则**：创意赛道6大组别之一，分高校学生组/青年设计师组；校赛-赛区赛-总赛三级晋级，总赛先网络评审再现场路演（5分钟介绍作品，侧重成果转化优势）。
   - **能力与工具要求**：
     ├─ 三维建模与场景设计
     ├─ 工具软件（Blender/Unity/Unreal/Maya）
     └─ 元宇宙概念与交互体验设计
   - **达标建议**：赛区获奖需作品完成度高；总赛获奖需设计完整、具备成果转化潜力。
2. **视觉与空间设计**
   - **赛制与规则**：覆盖视觉传达（VI/海报/包装/导视）与空间环境设计方向，网评+路演两阶段总赛。
   - **能力与工具要求**：
     ├─ 视觉传达设计能力
     ├─ 空间设计工具（SketchUp/3ds Max/Enscape）
     └─ 版式与展陈表达
   - **达标建议**：赛区获奖需主题契合、完成度高；总赛获奖需方案成熟、可落地转化。
3. **产品设计**
   - **赛制与规则**：工业/文创产品设计，提交效果图、三视图与设计说明，评审创新性、可行性与转化价值。
   - **能力与工具要求**：
     ├─ 产品造型与人机工学
     ├─ 工具软件（Rhino/KeyShot/SolidWorks）
     └─ 材质工艺与成本意识
   - **达标建议**：赛区获奖需方案完整；总赛获奖需创新与产业化可行性兼备（评审含产业方）。
4. **数字媒体设计**
   - **赛制与规则**：数字影像、交互、动画等数字媒体作品，网评+路演。
   - **能力与工具要求**：
     ├─ 数字影像/动画/交互制作
     ├─ 工具软件（After Effects/Premiere/Unity/Processing）
     └─ 视听语言与用户体验
   - **达标建议**：赛区获奖需作品完整规范；总赛获奖需技术实现与创意表达俱佳。
5. **中华传统文化IP开发设计**
   - **赛制与规则**：以中华传统文化为核心进行IP形象与衍生品设计，评审文化内涵与商业开发价值。
   - **能力与工具要求**：
     ├─ IP形象设计（造型/表情/世界观）
     ├─ 工具软件（Photoshop/AI/Blender）
     └─ 文化符号提取与再设计
   - **达标建议**：赛区获奖需IP形象完整；总赛获奖需文化解读准确、开发链条清晰。
6. **融合创新设计**
   - **赛制与规则**：鼓励跨学科、跨领域融合创新设计，新技术+新场景。
   - **能力与工具要求**：
     ├─ 跨学科整合能力
     ├─ 技术原型与设计表达
     └─ 创新场景定义能力
   - **达标建议**：赛区获奖需创新点明确；总赛获奖需融合深度与可转化性突出。
7. **定向主题赛道**
   - **赛制与规则**：每年发布约5个定向主题（如AIGC创新创业设计、华灿运河、乡村振兴等），须按指定主题创作，截止时间晚于创意赛道（约11月）。
   - **能力与工具要求**：
     ├─ 主题调研与在地文化理解
     ├─ 对应设计工具（视方向而定）
     └─ 命题解读与针对性创意
   - **达标建议**：获奖需紧扣主题、地域或产业特色鲜明。

### 第28项：米兰设计周——中国高校设计学科师生优秀作品展
- **简称**：米兰设计周（高校展）
- **赛道**：设计艺术
- **周期**：每年一届

- **赛道**：外语
- **周期**：每年一届
- **时间线**：报名及校园选拔约1-4月｜地区半决赛/决赛约4-7月｜全国半决赛/总决赛约10月（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：英语、翻译、国际新闻传播、涉外专业
- **组队**：个人赛
- **简介**：中国日报社指导、21世纪报社主办的全国最具影响力的英语演讲赛事，是国际公众英语演讲比赛（IPSC）中国区官方唯一选拔赛，口号"让世界倾听你的声音"，入选教育部竞赛排行榜。分大学组（本专科）与青年组（研究生须报青年组），往届全国总决赛一等奖获得者不可再参赛。

#### 子赛项
1. **已备演讲（定题演讲）**
   - **赛制与规则**：围绕年度主题自拟题目撰写原创演讲稿并录制不超过4分钟的演讲视频（不得透露姓名学校等个人信息），地区评委会打分；综合排名前10%-40%的选手晋级地区决赛（同一学校最多1名）。
   - **能力与工具要求**：
     ├─ 英语写作与演讲稿打磨
     ├─ 语音语调与镜头表现
     └─ 主题立意与逻辑结构
   - **达标建议**：通过初赛需语言流畅、内容切题（评分：内容45%、语言35%、综合印象20%）；进入全国赛需内容深度与表达感染力兼具。
2. **即席演讲（1V1对决）**
   - **赛制与规则**：地区半决赛起设置，每人2分钟，随机题目即兴发挥。
   - **能力与工具要求**：
     ├─ 即兴组织语言能力
     ├─ 知识储备与思辨
     └─ 临场心理素质
   - **达标建议**：需观点鲜明、条理清晰、言之有物。
3. **现场问答**
   - **赛制与规则**：评委现场提问，2分钟作答，考察应变与论证深度。
   - **能力与工具要求**：
     ├─ 听力理解与快速反应
     └─ 深度论证能力
   - **达标建议**：需回应切题、论证完整。

### 第56项：中华经典诵写讲大赛
- **简称**：中华经典诵写讲（诵写讲大赛）
- **赛道**：外语（语言文化/人文）
- **周期**：每年一届
- **时间线**：报名及语言文字知识测评约5-6月｜作品提交截止约7月｜省级评审约7-10月｜全国决赛评选约9月｜交流展示约12月（时间可能逐年变动）
- **难度**：★★
- **适合专业**：汉语言文学、中文、书法、播音主持、教育学
- **组队**：个人为主（诵读可多人合作）
- **简介**：教育部、国家语委主办的全国性中华经典文化赛事，设诵读、讲解、书写、篆刻四个赛项，主题"赓续文脉，典耀中华"，全程公益不收费，是中华经典文化传承领域权威性最高的国家级赛事。所有参赛者须先在官网参加语言文字知识及诗词常识测评，60分及以上方可参赛（多次测评取最高分）。

#### 子赛项
1. **"诵读中国"经典诵读大赛**
   - **赛制与规则**：选取古代/近现代/当代具有典范价值的经典诗文诵读（当代作品须正式出版或经省级以上主流媒体公开发布满2年），提交诵读视频，经校选、省级评审、全国决赛逐级选拔，可个人或多人合作诵读。
   - **能力与工具要求**：
     ├─ 普通话语音与朗诵技巧
     ├─ 经典文本理解与情感表达
     └─ 视频录制与后期（剪辑/字幕）
   - **达标建议**：省级获奖需语音标准、情感到位；全国获奖需经典理解深透、艺术表现力强。
2. **"诗教中国"诗词讲解大赛**

   - **能力与工具要求**：
     ├─ 古典诗词学养与文本细读
     ├─ 教学设计或演讲表达
     └─ 课件制作与讲述呈现
   - **达标建议**：省级获奖需讲解准确、重点突出；全国获奖需学术性与感染力兼备。
3. **"笔墨中国"汉字书写大赛**
   - **赛制与规则**：书法作品（硬笔/软笔）与书法文创两类，作品须为当年原创、禁止临摹。
   - **能力与工具要求**：
     ├─ 书法技法（楷/行/隶/篆等）
     ├─ 章法与创作能力
     └─ 书法文创产品设计意识
   - **达标建议**：省级获奖需用笔规范、章法完整；全国获奖需取法经典、风格成熟。
4. **"印记中国"师生篆刻大赛**
   - **赛制与规则**：手工篆刻、机器篆刻两类，提交印稿与作品照片。
   - **能力与工具要求**：
     ├─ 篆书基础与印面设计
     ├─ 篆刻技法（手工/机器）
     └─ 边款与印屏设计
   - **达标建议**：省级获奖需用字准确、篆刻到位；全国获奖需风格纯正、印屏美观。
