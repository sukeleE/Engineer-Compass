# 医学与技能类竞赛（排行榜第7、70、79、81、82、83项）

> 数据来源：全国普通高校大学生竞赛排行榜（高教学会2023版84项，2025沿用）+ 教育部/人社部/赛事官网公开通知。时间线均为约数，可能逐年变动。

---

### 第7项：中国大学生医学技术技能大赛
- **简称**：医学技术技能大赛
- **赛道**：医学技能（临床医学/中医学/预防医学/护理学）
- **周期**：每年一届
- **时间线**：报名约2-3月｜分区赛约4月｜全国总决赛约5-6月（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：临床医学（五年制、八年制）、中医学、预防医学、护理学
- **组队**：每校每赛道限报1队，3名正式队员+1名候补队员（共4人/队）
- **晋级方式**：校/省级选拔→分区赛（初赛、复赛、决赛）→全国总决赛（银奖争夺赛→金奖争夺赛→冠军争夺赛）；中医学赛道设预选赛，临床八年制赛道直接报名总决赛
- **简介**：教育部主办的医学学科领域最高级别国家级学科竞赛，排行榜第7位；覆盖临床、中医、预防、护理四大学科，重点考核"三基三严"与岗位胜任力，成绩被多校纳入推免保研与就业评价体系。注：药学专业未单设赛道。

#### 子赛项
1. **临床医学专业赛道（五年制/八年制）**
   - **赛制与规则**：分区赛+总决赛两级。总决赛银奖争夺赛采用客观结构化临床技能考试（OSCE，站点式考核），金奖争夺赛为赛道式（复合场景连续考核），冠军争夺赛为情境式（不同专业队伍混合编队综合演练）；评分遵循"质量为先、高分胜出"，同分时累计用时短者靠前，晋级成绩不带入下一场
   - **能力与工具要求**：
     ├─ 临床技能（体格检查/穿刺/心肺复苏/外科基本操作）
     ├─ 临床思维（病例分析、医嘱与病历书写）
     └─ 团队协作与人文关怀（急救场景角色分工）
   - **达标建议**：分区赛各组前约30%晋级总决赛；总决赛设金奖、银奖、铜奖及单项奖，获银奖及以上≈全国前40%，入围冠军争夺赛即全国顶尖（具体比例以当年通知为准）

2. **护理学专业赛道**
   - **赛制与规则**：分区赛初赛多站式、复赛赛道式、决赛单站式，总决赛OSCE站点式；重点考核基础护理、专科护理与急救护理的操作规范、无菌原则与节力原则
   - **能力与工具要求**：
     ├─ 基础护理（静脉输液/导尿/无菌技术）
     ├─ 专科与急救护理（心肺复苏/心电监护）
     └─ 人文关怀与护患沟通
   - **达标建议**：晋级总决赛即全国前列；全国金奖每届仅少数院校，获银奖以上即全国一流护理院校水平

3. **预防医学专业赛道**
   - **赛制与规则**：分区赛+总决赛，考核公共卫生案例分析、流行病学调查设计、现场采样与卫生应急处置，含数据分析与报告答辩环节
   - **能力与工具要求**：
     ├─ 流行病学与卫生统计学（SPSS/R数据分析）
     ├─ 公共卫生实践（流调设计、消杀、健康宣教）
     └─ 应急处置（突发公共卫生事件模拟演练）
   - **达标建议**：分区赛前约30%晋级总决赛；总决赛金银铜奖按总分排名，数据分析与汇报答辩是拉开差距的关键

4. **中医学专业赛道**
   - **赛制与规则**：预选赛+总决赛，考核中医四诊、辨证论治、方剂应用与针灸推拿技能操作，强调经典条文在临床场景中的运用
   - **能力与工具要求**：
     ├─ 中医诊断（望闻问切、辨证分析）
     ├─ 方药与针灸推拿操作
     └─ 中医临床思维（经典与临床结合）
   - **达标建议**：预选赛择优晋级总决赛；总决赛站点式评分，操作规范性与辨证准确性并重，获铜奖以上即全国前50%

### 第70项：全国大学生基础医学创新研究暨实验设计论坛（大赛）
- **简称**：基础医学创新论坛（现更名"全国大学生医学创新大赛暨'一带一路'国际竞赛"）
- **赛道**：基础医学创新研究（7个学科赛道×创新研究/实验设计两类）
- **周期**：每年一届
- **时间线**：报名约2-4月｜校级选拔约4-5月｜赛区复赛约6-7月｜全国总决赛约8月（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：临床医学、基础医学、法医学、口腔医学、预防医学、药学、中医学、医学检验、护理学等
- **组队**：3-5人/队（含队长1名）；各校按赛道限额推荐，如基础临床赛道每校约7项、法医学约2项、药学中医药约3项（名额以当年通知为准）
- **晋级方式**：校赛选拔→赛区复赛（网评+现场评审）→全国总决赛（现场答辩）；各赛道分设一、二、三等奖
- **简介**：高等学校大学生医学创新竞赛委员会主办的高水平医学本科生科研竞赛，自2023年起纳入排行榜（第70位）；分"创新研究"（已有实验成果）与"实验设计"（立项方案）两类，是医学本科生科研履历与保研的重要赛事，国际赛道已延伸至"一带一路"国家。

#### 子赛项
1. **基础临床赛道**
   - **赛制与规则**：按系统/疾病设7个亚组（呼吸循环血液、消化泌尿生殖、内分泌神经精神、免疫与病原、肿瘤、检验医学等）；创新研究类提交实验数据与论文，实验设计类提交研究方案；复赛网评后择优进总决赛现场答辩
   - **能力与工具要求**：
     ├─ 实验技能（细胞/分子生物学、动物实验）
     ├─ 科研工具（GraphPad/SPSS、文献检索与管理）
     └─ 汇报能力（PPT答辩、科研伦理）
   - **达标建议**：每校限项推荐，校赛脱颖而出即可代表学校；进入总决赛基本可获三等奖以上，一等奖≈全国前10-15%

2. **预防医学赛道**
   - **赛制与规则**：流行病学、环境/职业/营养/行为与健康、预防医学新技术3个亚组，创新研究与实验设计两类分别评审答辩
   - **能力与工具要求**：
     ├─ 流行病学与统计方法（SPSS/R）
     ├─ 人群研究设计（队列/病例对照）
     └─ 公共卫生数据分析与报告
   - **达标建议**：每校限报约2项；总决赛答辩重创新点与数据质量，一等奖多为有已发表论文或完整数据链支撑的队伍

3. **药学中医药赛道**
   - **赛制与规则**：药物学、药理学、中医基础与中西医结合、中药药理与剂型、药学中医药交叉研究5个亚组；重点支持药物新靶标发现与用现代科技阐明中医药原理
   - **能力与工具要求**：
     ├─ 药物实验（药效学、细胞筛选、ADMET评价）
     ├─ 分析仪器（HPLC/质谱、分子对接）
     └─ 中医药经典理论与现代技术结合
   - **达标建议**：每校限报约3项；有预实验数据+创新机制（如分子对接、人工智能辅助）的项目更易获一等奖

4. **口腔医学赛道**
   - **赛制与规则**：牙颌面发育与组织再生修复、口腔疾病病因与防治机制、口腔医学交叉研究（口腔微生态/人工智能）3个亚组
   - **能力与工具要求**：
     ├─ 组织病理与细胞实验
     ├─ 影像分析（CBCT/显微成像）
     └─ 生物材料与3D打印
   - **达标建议**：复赛按作品质量与答辩综合排名，获总决赛一、二等奖≈全国该赛道前25%

5. **法医学赛道**
   - **赛制与规则**：法医病理/临床/毒理/精神、法医物证/毒物分析/法医现场2个亚组，围绕司法实践中的生物与医学证据展开研究
   - **能力与工具要求**：
     ├─ 法医病理实验（组织学、尸体检验）
     ├─ 物证技术（PCR/STR分型）
     └─ 毒物分析与仪器应用
   - **达标建议**：该赛道规模较小，进入总决赛即前列；一等奖≈全国前10%

6. **交叉学科赛道**
   - **赛制与规则**：医工结合、生物信息学、人工智能辅助医学等交叉方向，作品须体现多学科融合创新
   - **能力与工具要求**：
     ├─ 编程（Python/R）与机器学习
     ├─ 组学数据分析（转录组/单细胞）
     └─ 医工交叉（可穿戴、医学图像处理）
   - **达标建议**：作品完整度+技术新颖度+应用价值综合评分，获二等奖以上≈全国前30%

7. **国际竞赛赛道（"一带一路"）**
   - **赛制与规则**：面向金砖及"一带一路"国家高校联合参赛，中英文双语汇报答辩，选题侧重全球健康议题
   - **能力与工具要求**：
     ├─ 科研设计与实验技能
     ├─ 学术英语（论文写作、答辩）
     └─ 国际合作与交流
   - **达标建议**：获奖标准同国内赛道，含金量对标国际学术会议级评审

### 第79项：全国职业院校技能大赛
- **简称**：国职赛（2024年起以"世界职业院校技能大赛"名义举办，简称世校赛）
- **赛道**：按专业大类设赛项（2023-2027执行规划：中职组ZZ编号、高职组GZ编号；2025年改革为42条赛道）
- **周期**：每年一届
- **时间线**：校赛约3-5月｜省赛约5-6月｜国赛争夺赛约6-9月｜全国总决赛约11月（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：高职/中职各专业大类——装备制造、电子信息、医药卫生、交通运输、土木建筑、财经商贸、轻工纺织、旅游服务等
- **组队**：每赛项2-5人（团体赛项为主，人数由各赛项规程规定，个人赛项1人）
- **晋级方式**：校级初赛→省级复赛（省赛一等奖晋级）→全国争夺赛→全国总决赛；获奖选手可获技能等级证书认定，部分省份纳入专升本免试/加分条件
- **简介**：教育部主办、我国职业教育领域规格最高、规模最大、参赛院校最多的技能竞赛，覆盖全部专业大类；2024年起升级为"世界职业院校技能大赛"并邀请国际队伍参赛，获奖是高职生技能水平最权威证明，对就业竞争力与升学提升显著。

#### 子赛项
1. **装备制造大类（中/高职组）**
   - **赛制与规则**：理论+实操结合，现场完成零件加工、设备装调、产线编程等任务；2025年起细分为机械设计与制造、机电设备安装与运维、智能装备应用、轨道/航空/船舶交通运输、汽车制造与维修等赛道；评分看加工精度、工艺规范、完成时间与安全文明生产
   - **技术栈**：
     ├─ CAD/CAM（UG/ProE/CATIA、数控仿真）
     ├─ 数控机床与多轴加工、增材制造
     └─ PLC（西门子/三菱）与工业机器人编程
   - **达标建议**：省赛一等奖（约前10%）获国赛资格；国赛按约10%/20%/30%设一、二、三等奖，获国赛一等奖可申请技师级技能等级认定

2. **电子信息大类（中/高职组）**
   - **赛制与规则**：2025年整合为电子电器与集成电路、新一代信息技术2条赛道；赛项含物联网、大数据、云计算、网络安全、集成电路、嵌入式系统等，考核系统搭建+功能实现+文档答辩
   - **技术栈**：
     ├─ 编程（Python/C/Java、嵌入式开发）
     ├─ 网络与安全（组网、5G、渗透测试）
     └─ 云计算/大数据平台（虚拟化、Hadoop）
   - **达标建议**：省一等奖晋级国赛；国赛一/二/三等奖约10%/20%/30%，获奖证书是电子信息类高职生就业与专升本的硬通货

3. **医药卫生大类（中/高职组）**
   - **赛制与规则**：2025年整合为医药生产与经营、医学技术、康复治疗与护理、健康养老与婴幼儿托育4条赛道；赛项含临床技能、护理技能、药学技能、中药传统技能、检验检疫技术、康复治疗技术、口腔修复工艺、老年护理与保健等，考核标准化病人操作+理论+人文关怀
   - **能力与工具要求**：
     ├─ 临床/护理操作（无菌、静脉输液、心肺复苏）
     ├─ 药学技能（处方调剂、制剂、检验分析）
     └─ 康复与照护（运动疗法、老年/婴幼儿照护）
   - **达标建议**：省一等奖晋级国赛；护理、药学等赛项国赛获奖（尤其团体奖）在护理/药学专升本与三甲医院招聘中显著加分

4. **交通运输、财经商贸等其它大类**
   - **赛制与规则**：按大类设赛项（汽车技术、智能网联汽车、会计实务、电子商务、智慧物流、土木建筑等），实行校赛-省赛-国赛三级赛制
   - **技术栈**：
     ├─ 汽车检测与维修（诊断仪、新能源汽车三电）
     └─ 数字化财经工具（财务软件、大数据分析、电商运营）
   - **达标建议**：获奖标准同上述大类（省一等奖进国赛，国赛一/二/三等奖约10%/20%/30%）

### 第81项：世界技能大赛
- **简称**：世赛（WorldSkills）
- **赛道**：六大领域60余个赛项（第48届共64项，2026年9月在上海举办，中国首次承办）
- **周期**：每两年一届（第47届2024年法国里昂，第48届2026年上海）
- **时间线**：全国选拔约世赛前1年（9-12月）｜国家集训约6-10个月｜比赛约当年9月（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：技工院校、职业院校及应用型本科工科专业——机电一体化、数控、电气、焊接、CAD、机器人、计算机网络、云计算、汽车技术等
- **组队**：个人赛项1人/项；团体赛项按项目组队（机电一体化2人、机器人系统集成3人等，以赛项规则为准）
- **晋级方式**：中国由人社部组队——全国职业技能大赛等平台选拔→国家集训队→集训考核"5进1/3进1"→正选选手（另设备选）代表中国参赛
- **简介**：世界技能组织（WSI）举办的全球最高水平职业技能赛事，被誉为"世界技能奥林匹克"；中国自2010年加入、2015年起连续位居金牌榜和团体总分第一，获奖选手可获"全国技术能手"等最高技能荣誉与高技能人才待遇。

#### 子赛项
1. **机电一体化（制造与工程技术领域）**
   - **赛制与规则**：2人组队，约4天共20小时内完成自动化生产系统的设计、装配、气路电路连接、PLC编程与联调，模拟真实产线故障场景；评分看功能完成度、工艺质量、安全规范与团队协作
   - **技术栈**：
     ├─ PLC编程（西门子/三菱）与触摸屏组态
     ├─ 电气/气动回路设计与装配
     └─ 传感器应用与机械装调
   - **达标建议**：中国队自2015年起多次蝉联该赛项金牌；需先在全国选拔赛获前5名入选集训队，再经多轮"5进1"考核晋级国家队

2. **CAD机械设计**
   - **赛制与规则**：个人赛，约4天完成机械产品概念设计、详细设计、工程图与装配爆炸图（含逆向建模），评分看设计质量、标准规范与效率
   - **技术栈**：
     ├─ CAD软件（SolidWorks/CATIA/Inventor）
     ├─ 三维建模与参数化设计
     └─ 工程图标准与BOM管理
   - **达标建议**：全国选拔赛前5名入集训队，集训淘汰制最终1名正选代表中国参赛；世赛获牌需进入世界前6名

3. **自主移动机器人（原移动机器人赛项）**
   - **赛制与规则**：2人组队，完成移动机器人机械结构搭建、传感器配置、运动控制与自主任务编程（巡线/取放/避障），现场任务含随机变化
   - **技术栈**：
     ├─ 嵌入式/单片机（STM32）与ROS
     ├─ 传感器融合（摄像头、激光、编码器）
