### 第19项：全国大学生机器人大赛（CURC）
- **简称**：机器人大赛/机甲大师
- **赛道**：电子机器人
- **周期**：每年一届
- **时间线**：报名约10-11月（RoboMaster）/3-5月（RoboCon）｜分区赛约5-6月｜总决赛约7-8月
- **难度**：★★★★★
- **适合专业**：自动化、机械、电子、计算机、人工智能
- **组队**：RoboMaster每队10-35人（同一学校原则上1支队伍，2-5所无独立参赛资格学校可跨校组联队）；RoboCon按赛项规定每校限报1-2支，每队6-10人
- **简介**：国内最高水平的大学生机器人综合竞技赛事，由全国大学生机器人大赛组委会主办，中国高等教育学会、中国工程院战略咨询中心指导；含ROBOCON、ROBOMASTER、ROBOTAC三大赛项（ROBOTAC另见第80项），被公认为含金量最高的机器人学科竞赛之一。

#### 子赛项
1. **RoboMaster机甲大师超级对抗赛（RMUC）**
   - **赛制与规则**：红蓝双方7V7机器人团队对抗，操作手第一人称视角遥控，限时7分钟，发射弹丸攻击对方机器人与基地，摧毁基地者胜（时间结束按基地剩余血量判定）。兵种含英雄（42mm大弹丸吊射）、步兵（17mm弹丸）、工程（采矿兑换经济、救助队友）、空中（无人机侦察打击）、哨兵（全自动防守）、飞镖系统（远程打击前哨站/基地）、雷达（全局视野）。赛程：每年10-11月报名 → 次年3-4月中期检查 → 5-6月区域赛 → 7-8月复活赛与全国总决赛（深圳）；含机器人形态考核与研发进度考核，未通过中期检查无参赛资格。
   - **技术栈**：
     ├─ 机械结构
     │  ├─ 云台/底盘/发射机构（SolidWorks）
     │  └─ 材料与加工（CNC/3D打印/碳纤维）
     ├─ 电控
     │  ├─ STM32嵌入式开发/DJI M3508电机
     │  └─ CAN/UART通讯与传感器融合
     ├─ 视觉算法
     │  ├─ OpenCV自瞄识别/能量机关激活
     │  └─ 深度相机/相机标定
     └─ 操作与战术
        ├─ 第一视角遥控/队内指挥
        └─ 兵种协同与经济资源规划
   - **达标建议**：通过中期检查并完整参赛即可获区域赛奖项；区域赛获奖（二等以上）通常需具备自研底盘+基础射击+视觉识别能力，校队规模15人以上；打进全国赛32强可获全国奖项，全国一等奖为顶级战队水平。

2. **RoboMaster机甲大师高校联盟赛（RMUL）**
   - **赛制与规则**：每年3-4月在多个站点举办（2026赛季设9站：安徽、华南、山东、重庆、东北、江苏、华北、上海、四川），设3V3对抗赛、步兵对抗赛、工程挑战赛三个赛项，2-12人/队；是超级对抗赛的预备与选拔通道，3V3小组赛晋级队伍可获得下赛季RMUC报名资格；同一项目同一学校原则上仅1支队伍，不允许联队。
   - **技术栈**：
     ├─ 机器人本体
     │  ├─ 步兵/工程机器人底盘（SolidWorks）
     │  └─ 轻量化与模块化设计
     ├─ 电控
     │  ├─ STM32/直流无刷电机驱动
     │  └─ 遥控与数据回传
     ├─ 视觉与决策
     │  ├─ OpenCV目标识别
     │  └─ 攻防策略
     └─ 备赛体系
        ├─ 站队选拔与集训
        └─ 完整形态考核
   - **达标建议**：以"能上场、能对抗"为目标，通过完整形态考核并在站赛取胜；站赛获奖可作为次年RMUC的跳板，是新手队伍的首选入口。

3. **RoboMaster机甲大师高校单项赛（RMUT）**
   - **赛制与规则**：仅需研发1台机器人完成单项挑战，研发成本低，适合新生队。项目含：步兵竞速与智能射击（穿越复杂地形并激活能量机关、命中目标）、工程采矿（场地采矿并最快兑换）、飞镖打靶（飞镖射击前哨站/基地）、英雄吊射（42mm弹丸远程吊射基地）；按命中环数/任务完成时间计分。
   - **技术栈**：
     ├─ 步兵组
     │  ├─ 底盘竞速与地形通过性
     │  └─ 智能射击（OpenCV瞄准）
     ├─ 工程组
     │  ├─ 机械臂抓取机构
     │  └─ 矿石识别与搬运
     ├─ 飞镖组
     │  ├─ 飞镖发射机构设计
     │  └─ 弹道标定
     └─ 英雄组
        ├─ 42mm发射机构
        └─ 吊射轨迹计算
   - **达标建议**：1-2台机器人即可参赛，完成单项任务即有机会获奖，适合作为进入机甲大师体系的入门赛项。

4. **ROBOCON（2025第24届主题"飞身上篮"）**
   - **赛制与规则**：机器人竞技赛，2025年在江阴（7月9-15日）与深圳（8月5-11日）两地举行；"飞身上篮"为机器人篮球赛，红蓝双方各派2台机器人对抗，20秒攻防转换，完成运球、传球、投篮动作，扣篮得7分高分；赛制为预选赛（进32强）→小组循环赛→复赛（淘汰制）。报名约3-5月，参赛队员须为全日制本科生/专科生，每校最多2支队伍；另设技能挑战赛、仿生足式机器人挑战赛（研究生可参加，每校最多3支）、机器人排球挑战赛。
   - **技术栈**：
     ├─ 机械结构
     │  ├─ 轮式/仿人底盘与投篮机构（SolidWorks）
     │  └─ 轻量化设计与3D打印
     ├─ 电控
     │  ├─ STM32/伺服电机控制
     │  └─ 无线遥控与多机通讯
     ├─ 视觉与感知
     │  ├─ OpenCV球体/篮筐识别
     │  └─ 单目测距与场地定位
     └─ 运动控制
        ├─ 投篮轨迹规划
        └─ 运球/传球动作控制
   - **达标建议**：完成场地任务（能投篮命中）可获三等奖；进入16强获二等奖，冠亚季军需稳定命中率+快速攻防；队伍需机械+电控+视觉完整分工。

### 第37项：中国机器人大赛暨RoboCup机器人世界杯中国赛
- **简称**：中国机器人大赛（CRC）/RoboCup中国赛
- **赛道**：电子机器人
- **周期**：每年一届
- **时间线**：报名约3月（RoboCup赛区）/6-8月（机器人大赛赛区）｜省赛/专项赛约7-8月｜总决赛约10月
- **难度**：★★★★
- **适合专业**：自动化、机械、电子、计算机、人工智能、通信
- **组队**：各赛项不同，通常2-5人/队（多智能体协同类赛项可更大），可跨校按赛区规定组队
- **简介**：由中国自动化学会主办（1999年创办），分RoboCup机器人世界杯中国赛赛区与中国机器人大赛赛区两大体系，2025年第27届（石家庄，10月17-19日）有300余所高校1600余支队伍晋级决赛，是覆盖面最广的综合性机器人赛事之一。

#### 子赛项
1. **RoboCup赛区（足球/救援/家庭服务）**
   - **赛制与规则**：对标RoboCup国际标准项目，2025年5月1-4日在北京举办，官方报名截止约3月20日；含RoboCup足球（FIRA小型组、中型组、仿真组）、RoboCup救援、RoboCup@Home家庭服务等国际标准赛项，考验多智能体协同、实时决策与系统可靠性，优胜队可晋级国际赛。
   - **技术栈**：
     ├─ 多智能体协同
     │  ├─ 全局视觉/场外裁判系统
     │  └─ 角色分配与传球策略
     ├─ 机器人本体
     │  ├─ 全向轮底盘（小型组）
     │  └─ 射门/传球机构
     ├─ 决策算法
     │  ├─ 队形策略/行为树
     │  └─ 强化学习训练
     └─ 仿真平台
        ├─ Webots/Simuro仿真
        └─ 虚实迁移
   - **达标建议**：能完成基础比赛对抗（5v5小型组进球）即获三等奖以上；进入全国前8强需稳定的决策策略与抗干扰通信。

2. **武术擂台赛（仿人格斗/人形散打）**
   - **赛制与规则**：机器人擂台对抗，含仿人格斗、仿人散打等视觉挑战项目，机器人在擂台上将对手推出/击倒得分，淘汰制晋级；考核结构强度、平衡控制与对抗策略。
   - **技术栈**：
     ├─ 机器人本体
     │  ├─ 仿人关节/底盘（舵机驱动）
     │  └─ 抗冲击结构设计
     ├─ 感知与控制
     │  ├─ 对手识别与跟踪（OpenCV）
     │  └─ 姿态平衡控制（IMU）
     └─ 对抗策略
        ├─ 进攻/防守切换
        └─ 擂台边界检测
   - **达标建议**：完成3轮以上对抗可获三等奖，机械强度+防出界策略是关键。

3. **服务机器人赛**
   - **赛制与规则**：真实场景任务赛，机器人完成导览、物品递送、人机交互等任务，按任务完成度与时间计分；2025年列入大学组大项，设多场景任务站。
   - **技术栈**：
     ├─ 自主导航
     │  ├─ 激光雷达SLAM（ROS）
     │  └─ 路径规划（A*/DWA）
     ├─ 人机交互
     │  ├─ 语音识别/合成
     │  └─ 机械臂抓取
     └─ 任务调度
        ├─ 场景理解（YOLO目标检测）
        └─ 状态机任务编排
   - **达标建议**：完成3个以上任务站即获三等奖；稳定自主导航+语音交互可冲击一二等奖。

4. **无人机挑战赛（多机协同）**
   - **赛制与规则**：实物飞行与集群协同搜索结合，含无人机多机协同作业赛项，完成障碍穿越、定点悬停、物资投放、协同搜索等任务，按完成度与用时计分。
   - **技术栈**：
     ├─ 飞控系统
     │  ├─ PX4/ArduPilot飞控
     │  └─ 多机编队通讯
     ├─ 视觉与避障
     │  ├─ 机载视觉（OpenCV/深度相机）
     │  └─ 障碍规避与目标识别
     └─ 任务执行
        ├─ 定点悬停/物资投放
        └─ 集群协同搜索
   - **达标建议**：单机完成障碍穿越即有三等奖基础，多机协同完赛可获二等奖。

5. **水下作业机器人赛**
   - **赛制与规则**：水下机器人完成观察、抓取、定点作业等任务（2025年设大学组正式大项），按任务完成度计分。
   - **技术栈**：
     ├─ 本体设计
     │  ├─ 密封舱体/推进器布局
     │  └─ 防水电控（水下连接器）
     ├─ 感知
     │  ├─ 水下摄像头/声呐
     │  └─ 图像增强与目标识别
     └─ 控制
        ├─ 深度/航向PID控制
        └─ 机械手抓取作业
   - **达标建议**：完成观察与定点悬停任务即获三等奖，加入机械手抓取可冲击二等奖。

6. **四足仿生机器人赛（含快递运送）**
   - **赛制与规则**：四足仿生机器人完成货物取送、地形行走等任务（2025年设快递运送赛项），考核步态稳定性与自主导航。
   - **技术栈**：
     ├─ 机械本体
     │  ├─ 四足腿结构（舵机/关节）
     │  └─ 轻量化材料
     ├─ 运动控制
     │  ├─ 步态算法（Trot等）
     │  └─ IMU姿态稳定
     └─ 任务感知
        ├─ 物体识别与取送（OpenCV）
        └─ 路径导航
   - **达标建议**：稳定行走完成送达即获三等奖，双足/四足混合地形通过性是获奖分水岭。

### 第40项：睿抗机器人开发者大赛（RAICOM）
- **简称**：睿抗大赛/RAICOM
- **赛道**：电子机器人
- **周期**：每年一届
- **时间线**：报名约3-6月｜省赛（区域选拔赛）约5-7月｜全国总决赛约8-11月
- **难度**：★★★★
- **适合专业**：计算机、人工智能、自动化、机械、电子信息、工业设计、艺术设计
- **组队**：各赛项不同：团队赛1-5人/队，部分赛项为双人赛或个人赛；可跨年级组队
- **简介**：由工业和信息化部人才交流中心主办的全国性学科竞赛，设CAIA数字文化创意、CAIP信息技术创新、CAIR工程竞技、CAIM工程创客四大赛道（赛道逐年调整），2025年全国总决赛在杭州、深圳等地举行，赛项贴近产业真实场景，行业认可度高。

#### 子赛项
1. **CAIR工程竞技赛道（强体赛道）**
   - **赛制与规则**：聚焦实体机器人实操与真实场景任务，2025年含智能侦察（无人车障碍规避与目标识别）、空中侦察（无人机障碍穿越、精准悬停与物资投放）、平安城市（复杂地形行驶、安防预警与物资运输）、物流小车、四足多模态巡检、足球竞技、智慧果园、慧眼识果等赛项；省赛现场竞技，按任务完成度与用时计分，优胜晋级全国总决赛。
   - **技术栈**：
     ├─ 无人车平台
     │  ├─ ROS/STM32底盘控制
     │  └─ 激光雷达+深度相机感知
     ├─ 视觉算法
     │  ├─ OpenCV/YOLO目标识别
     │  └─ 障碍规避与自主导航
     ├─ 无人机平台
     │  ├─ PX4飞控/机架组装
     │  └─ GPS+光流定位
     └─ 任务执行
        ├─ 物资识别与运输
        └─ 路径规划（A*算法）
   - **达标建议**：无人车完成障碍穿越+目标识别即有三等奖基础；稳定完成物资运输/精准投放可冲击一二等奖。

2. **CAIM工程创客赛道（工创赛道）**
   - **赛制与规则**：聚焦智能制造与"虚实融合"，2025年含机器人创新应用仿真设计、协作机械臂挑战赛（精准控制与人机协同）、智能制造数字孪生研创（工业场景孪生系统）、"三品"创意与3D打印产教融合赛（设计向实物转化）、机器视觉系统创新等；以作品提交+评审答辩为主。
   - **技术栈**：
     ├─ 数字孪生平台
     │  ├─ 3D建模（SolidWorks/3ds Max）
     │  └─ 虚实映射（Unity/UE）
     ├─ 自动化仿真
     │  ├─ 协作机械臂仿真（ROS/MoveIt）
     │  └─ 产线工艺流程设计
     └─ 创新应用
        ├─ 机器视觉系统集成
        └─ 3D打印实物转化
   - **达标建议**：提交完整仿真作品+设计文档可获三等奖；含实物样机/机械臂真实控制可冲击一二等奖。

3. **CAIA数字文化创意赛道（设计赛道）**
   - **赛制与规则**：主打"科技+艺术"跨学科融合，2025年含数字人（虚拟交互设计）、宋韵新风（传统文化数字化表达）、智绘未来（视觉传达/数字视觉创作）、智居环境（空间场景设计）、艺术疗愈（人机情感交互）等赛项；作品提交+评审，每队1-5人。
   - **技术栈**：
     ├─ 数字人技术
     │  ├─ 3D建模与绑定（Blender/Maya）
     │  └─ 动作捕捉/驱动（UE/Live2D）
     ├─ 交互开发
     │  ├─ 语音交互（ASR/TTS）
     │  └─ Web/移动端展示开发
     └─ 创意内容
        ├─ 传统文化数字化表达
        └─ AI生成内容（AIGC）
   - **达标建议**：完成主题作品+交互演示即有三等奖基础；技术完成度与创意叙事双优可冲击一二等奖。

4. **CAIP信息技术创新赛道**
   - **赛制与规则**：聚焦软件开发与信息技术应用，2025年设算法编程、AI智能体开发应用等赛题（赛项随年度调整，以官网通知为准）；以在线竞赛/作品提交方式进行。
   - **技术栈**：
     ├─ 算法与编程
     │  ├─ Python/C++程序设计
     │  └─ 数据结构与算法
     ├─ AI应用开发
     │  ├─ 大模型API/智能体框架
     │  └─ 全栈应用开发
     └─ 交付成果

#### 子赛项
1. **对抗赛**
   - **赛制与规则**：多机器人团队对抗竞技，各队多台机器人（轮式/异型足）在场地争夺、对抗，通过攻击/推撞/夹持得分或夺旗式目标得分，比赛过程中操作手与指导教师须在场地外指定操作区；流程为校内赛→区域赛→全国赛（预选赛+总决赛，按区域赛/预选赛得分排名晋级）。
   - **技术栈**：
     ├─ 机械结构
     │  ├─ 轮式/异型足底盘（SolidWorks）
     │  └─ 攻击机构（夹持/推撞/抬升）
     ├─ 电控
     │  ├─ STM32/电机驱动
     │  └─ 无线遥控（2.4G）
     ├─ 视觉与感知
     │  ├─ 场地识别（OpenCV）
     │  └─ 队友/对手定位
     └─ 战术
        ├─ 团体配合进攻
        └─ 防守与夺分策略
   - **达标建议**：机器人能上场比赛完成对抗即有三等奖基础；机械强度+多机战术配合可冲击一二等奖，全国八强需完整机械/电控/战术体系。

2. **挑战赛（含仿真挑战赛）**
   - **赛制与规则**：单项任务挑战，含异型足竞速赛、人形功夫搏击赛、足球机器人挑战赛、智慧城市无人驾驶赛、智能服务机器人赛等，及仿真挑战赛（每校最多4支队伍）；按任务完成度/成绩排名。
   - **技术栈**：
     ├─ 仿真平台
     │  ├─ 机器人仿真（Webots/Unity）
     │  └─ 强化学习训练
     └─ 真实挑战
        ├─ 异型足竞速
        └─ 人形功夫搏击
   - **达标建议**：仿真赛纯算法可参与、成本低，易获省级奖；实物单项赛完成竞速/搏击任务即获奖。

3. **设计赛（三维数字设计赛）**
   - **赛制与规则**：创意设计赛，含对抗机器人方案设计赛、三维数字创意设计赛等（2025年三维数字设计赛报名5月1-16日，作品经艾迪普元数云平台提交）；提交3D模型/渲染与设计文档，评审评奖。
   - **技术栈**：
     ├─ 三维建模
     │  ├─ SolidWorks/3ds Max建模
     │  └─ 数字场景搭建
     └─ 创意表达
        ├─ 渲染与动画
        └─ 设计文档
   - **达标建议**：完成建模+渲染+文档即有三等奖基础；机械结构合理性+视觉效果优秀者可冲击一二等奖。
