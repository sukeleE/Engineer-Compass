### 第4项：ACM-ICPC国际大学生程序设计竞赛
- **简称**：ACM/ICPC
- **赛道**：数学基础
- **周期**：每年一届
- **时间线**：校赛约3-4月｜省赛约5-6月｜中国女生赛约3-4月｜区域赛约9-11月｜EC-Final约12月-次年2月｜全球总决赛约9月（时间可能逐年变动）
- **难度**：★★★★★
- **组队**：3人/队（另可设1名替补，全队含替补最多4人）
- **适合专业**：计算机、软件、数学、电子
- **简介**：全球规模最大、历史最悠久的国际大学生程序设计竞赛，由国际计算机协会（ACM）主办；区域赛金银铜奖牌及决赛排名被互联网大厂、保研推免普遍认可，是算法岗就业与名校读研的"硬通货"。

#### 子赛项
1. **校赛与省赛（晋级通道）**
   - **赛制与规则**：校赛通常约3-4月、省赛约5-6月举办；线上或线下OJ赛制，4-5小时解6-10题，按解题数+罚时排名；校赛前若干名入选校集训队，省赛获奖队伍获得晋级区域赛资格。
   - **技术栈**：
     ├─ 算法与数据结构
     │  ├─ 枚举/模拟/贪心/搜索/二分
     │  └─ 图论/动态规划基础
     ├─ 编程语言（C++为主）
     └─ 队内分工与debug策略
   - **达标建议**：校赛前10%入选集训队并开始系统训练；省赛获得一、二等奖即具备区域赛水平线。
2. **ICPC区域赛**
   - **赛制与规则**：5小时现场赛，3人1队1台电脑；按解出题数排名，同题数按罚时排序（每题罚时=该题AC时间+20分钟×该题错误提交次数）；比赛最后一小时榜单封榜，结束时揭晓；提交由在线判题系统即时评测，错误提交不扣分只加罚时；区域赛设金/银/铜牌，获奖队伍约在参赛队前20%-25%。
   - **技术栈**：
     ├─ 算法与数据结构
     │  ├─ 图论/动态规划/数论/计算几何
     │  └─ 字符串/网络流/组合数学
     ├─ 编程语言（C++为主）
     └─ 团队协作与调试策略
   - **达标建议**：稳定解出2-3题可获得铜牌（约前25%）；银牌约需解出3-4题（前12%左右）；金牌约前6%。铜牌及以上即可写入简历并获得保研加分与大厂算法岗实习机会。
3. **ICPC中国女生赛**
   - **赛制与规则**：面向全女生的团队赛，每年约3-4月举办，3人1队（允许1名替补），5小时6-10题ACM赛制；成绩优异队伍（冠军等）可获得EC-Final参赛资格。
   - **技术栈**：
     ├─ 算法与数据结构（同区域赛体系）
     ├─ 编程语言（C++为主）
     └─ 团队分工与罚时管理
   - **达标建议**：参赛即省级以上赛事经历，获奖牌队伍数量约参赛队前30%；冠军直通EC-Final。
4. **EC-Final（东亚区决赛）**
   - **赛制与规则**：由各区域赛排名靠前队伍晋级（约100-150支，2025-2026赛季于2026年1-2月在杭州举办），5小时ACM赛制，按解题数+罚时排名，设金/银/铜牌；是东亚地区年度最高水平较量。
   - **技术栈**：
     ├─ 高级算法
     │  ├─ 高级数据结构（LCT/可持久化/平衡树）
     │  └─ 博弈论/FFT/线性规划/高级图论
     ├─ 编程语言（C++，注重实现速度与正确性）
     └─ 高强度团队配合（分工读题/并行解题）
   - **达标建议**：晋级即证明进入全国百强队伍行列；获奖牌可获大厂算法岗面试直通、保研竞赛加分顶格。
5. **全球总决赛（World Finals）**
   - **赛制与规则**：全球各区域赛冠军及优秀队伍汇聚（全球约130-140支，中国通常约10支），5小时ACM赛制，设全球冠军及金银铜奖牌（近年总决赛约9月举办，如2025年印尼雅加达、2024年哈萨克斯坦阿斯塔纳）。
   - **技术栈**：
     ├─ 顶尖算法体系（全领域覆盖）
     │  ├─ 理论计算机（图论/组合/数论/几何全覆盖）
     │  └─ 速度与正确性工程（模板库/对拍/极限优化）
     ├─ 编程语言（C++17/20 与高性能实现）
     └─ 五小时全程决策与心态管理
   - **达标建议**：中国队常态进入全球前20名；入围总决赛即为国内顶级水平（保研、大厂绿卡级履历）。

### 第25项：中国大学生计算机设计大赛
- **简称**：计算机设计大赛 / 4C大赛
- **赛道**：综合
- **周期**：每年一届
- **时间线**：校赛约3-4月｜省赛约4-5月｜国赛（按赛区）约7-8月（2025年设上海、南京南、济南、杭州、南京东5个决赛区，7月中至8月中举行）（时间可能逐年变动）
- **难度**：★★★
- **组队**：2-5人/队（指导教师不超过2人，国赛仅限本科生作品）
- **适合专业**：计算机、软件、人工智能、数字媒体、艺术设计、物联网、大数据、教育技术
- **简介**：教育部计算机相关教指委发起、全国性覆盖面最广的"作品型"综合大赛，以"以赛促学、以赛促教、以赛促创"为宗旨；采用校赛—省赛—国赛三级晋级，国赛按作品类别分赛区现场答辩，获奖对保研综测加分认可度高。

#### 子赛项
1. **软件应用与开发**
   - **赛制与规则**：提交原创软件作品（含Web应用/管理系统/移动App/算法设计与应用），校赛3-4月选拔、省赛作品4-5月评审、国赛7-8月现场答辩；作品须为当年6月30日前完成的原创成果，一稿不得多投；含组委会命题的"软件应用与开发专项赛"。
   - **技术栈**：
     ├─ Web全栈（Vue/React + Spring Boot/Node.js + MySQL）
     ├─ 移动应用（Android/iOS/鸿蒙开发）
     ├─ 算法与AI应用（Python/MATLAB/机器学习）
     └─ 文档与答辩（需求设计/演示视频/现场讲解）
   - **达标建议**：省赛一、二等奖晋级国赛；国赛获奖比例约60%（一奖约10%、二奖约20%、三奖约30%），获国赛三等奖即有保研综测加分。
2. **微课与AI辅助教学**
   - **赛制与规则**：提交微课、教学课件、虚拟仿真实验、教学案例等教育类作品，2025年重点支持人工智能通识课方向，设专项赛；初评+现场答辩。
   - **技术栈**：
     ├─ 微课制作（PPT/录屏/剪辑）
     ├─ AI辅助教学工具（大模型课件生成/虚拟仿真平台）
     └─ 教学设计（教案/脚本/课堂展示）
   - **达标建议**：省赛获奖并晋级国赛；国赛答辩突出教学设计与AI应用结合的创新点。
3. **物联网应用**
   - **赛制与规则**：城市管理、医药卫生、运动健身、数字生活、行业应用及物联网专项等小类，提交软硬件结合的物联网系统作品，现场答辩演示。
   - **技术栈**：
     ├─ 嵌入式开发（STM32/ESP32/Arduino，C语言）
     ├─ 传感与通信（传感器/蓝牙/WiFi/MQTT）
     ├─ 平台与App（云平台/小程序/数据可视化）
     └─ 演示与答辩（实物演示/PPT）
   - **达标建议**：实物演示完整、功能落地即可冲省奖；国赛突出行业场景价值。
4. **大数据应用**
   - **赛制与规则**：设大数据实践赛与大数据主题赛，围绕真实行业数据做分析、挖掘、可视化应用，初评+现场答辩。
   - **技术栈**：
     ├─ Python数据分析（pandas/numpy/爬虫）
     ├─ 机器学习（scikit-learn/LightGBM/PyTorch）
     ├─ 大数据平台（Hadoop/Spark/数据仓库）
     └─ 可视化（ECharts/Tableau/BI工具）
   - **达标建议**：完整的数据"采集-清洗-分析-可视化-结论"闭环作品可获省奖；国赛需体现业务洞察深度。
5. **人工智能应用**
   - **赛制与规则**：人工智能实践赛+人工智能挑战赛，面向智能城市、家居、医疗等领域，提交基于AI的软硬件作品，现场答辩；挑战赛设命题赛题。
   - **技术栈**：
     ├─ 深度学习（PyTorch/TensorFlow，CNN/Transformer）
     ├─ 数据与训练（数据集构建/微调/推理部署）
     ├─ 应用开发（Web/小程序/边缘端部署）
     └─ 模型可解释与演示
   - **达标建议**：模型效果+应用价值完整呈现可冲省奖；国赛获奖需创新点与工程完成度兼备。
6. **信息可视化设计**
   - **赛制与规则**：围绕主题（如中华自然科学等）做信息图表、数据可视化、交互可视化作品，初评+现场答辩。
   - **技术栈**：
     ├─ 可视化开发（ECharts/D3.js/Tableau）
     ├─ 前端交互（HTML/CSS/JavaScript/动效）
     ├─ 数据整理与分析
     └─ 视觉设计（版式/配色/信息层级）
   - **达标建议**：视觉表现+数据叙事能力达标即可竞争省奖；国赛看重主题契合与交互体验。
7. **数媒类（数媒静态设计/数媒动漫与短片/数媒游戏与交互设计）**
   - **赛制与规则**：三大类按普通组与专业组分别评奖，作品含平面设计、环境产品设计、微电影、动画、游戏、VR交互等；按主题创作（2025年主题"中国古代物理"），初评+答辩。
   - **技术栈**：
     ├─ 静态设计（Photoshop/Illustrator/建模渲染）
     ├─ 动漫短片（剪辑/动画制作/AI辅助创作）
     └─ 游戏与交互（Unity/UE/游戏设计/VR）
   - **达标建议**：主题契合、完成度高即有省奖竞争力；国赛获奖作品通常在视觉与叙事上双优。
8. **计算机音乐创作与国际生"汉学"**
   - **赛制与规则**：计算机音乐创作（电子音乐/音乐制作）与国际生"汉学"主题作品，面向相应作品方向，初评+答辩。
   - **技术栈**：
     ├─ 音乐制作（编曲软件/DAW/数字音色设计）
     └─ 汉学作品（多媒体内容创作/跨文化设计）
   - **达标建议**：按作品质量竞争省奖与国奖，量少但获奖率相对友好。

### 第26项：中国高校计算机大赛
- **简称**：C4大赛
- **赛道**：综合
- **周期**：每年一届
- **时间线**：各模块全年陆续开展：天梯赛约4月｜大数据挑战赛约4-8月｜移动应用创新赛约3-6月｜网络技术挑战赛约4-8月｜人工智能创意赛约6-11月｜智能交互创新赛约4-8月｜AIGC创新赛约4-8月｜嵌入式挑战赛约3-8月（时间可能逐年变动）
- **难度**：★★★☆
- **组队**：视模块而定——天梯赛10人/队，其余模块2-6人/队
- **适合专业**：计算机、软件、人工智能、大数据、通信、物联网、数字媒体
- **简介**：由全国高等学校计算机教育研究会主办（2025年为第十届），是覆盖程序设计、大数据、移动应用、网络技术、人工智能、嵌入式等方向的"赛事集群"，入选全国普通高校竞赛排行榜；其中团体程序设计天梯赛被誉为"高校程序设计领域的奥林匹克"，分赛模块多、学生覆盖面广。

#### 子赛项
1. **团体程序设计天梯赛**
   - **赛制与规则**：3月报名、4月全国总决赛（线上+线下结合）；10人/队、个人独立竞技、团队计分；题目分基础级、进阶级、登顶级三个梯级，设团队分数解锁机制与个人有效分机制；组别为珠峰争鼎组、华山论剑组、沧海竞舟组；支持C、C++、Java、Python；2025年吸引613所高校1972支队伍参赛，设全国团队一/二/三等奖及个人奖。
   - **技术栈**：
     ├─ 基础程序设计（C/C++/Java/Python）
     │  ├─ 输入输出/字符串/模拟/排序
     │  └─ STL与常用库
     ├─ 算法与数据结构
     │  ├─ 图论/动态规划/搜索
     │  └─ 并查集/线段树/数论
     └─ 团队策略与分工（爬级顺序/时间分配）
   - **达标建议**：团队总分进入全国前30%获全国三等奖，前15%获二等奖；个人获得有效分（完整AC一题）即满足多数学校综测门槛。
2. **大数据挑战赛**
   - **赛制与规则**：清华大学等单位主办，以真实业务数据为赛题（2025年赛题：预测股价涨跌）；4月热身赛、6月初赛、7月复赛、8月全国总决赛（线下答辩，2025年8月28日在清华大学举行）；2025年吸引448所高校2600余名选手。
   - **技术栈**：
     ├─ 编程语言（Python为主）
     ├─ 数据分析与特征工程
     │  ├─ pandas/numpy/scikit-learn
     │  └─ 时序特征/缺失值处理
     ├─ 机器学习与深度学习
     │  ├─ LightGBM/XGBoost/随机森林
     │  └─ PyTorch（LSTM/Transformer等时序模型）
     └─ 数据可视化与答辩报告（ECharts）
   - **达标建议**：复赛进入全国前约10%可晋级决赛；决赛获奖（一二三等奖）对数据类岗位求职加分明显。
3. **移动应用创新赛**
   - **赛制与规则**：浙江大学与苹果公司联合承办，基于iOS/iPadOS/visionOS设计开发移动应用；设启明（创意）、启迪（创新）、启航（创业）及高职赛道；约3月报名提交作品、6月复赛、暑期决赛答辩。
   - **技术栈**：
     ├─ 移动端开发（Swift/SwiftUI，Xcode）
     │  ├─ 界面与交互编程
     │  └─ Core ML/ARKit/系统框架
     ├─ 产品设计与UI/UX（Figma原型）
     ├─ 后端与数据（可选：云服务/API/数据库）
     └─ 演示与答辩（Demo视频/现场路演）
   - **达标建议**：完成可运行的iOS应用并有清晰产品定位即可冲击复赛；进入全国决赛即获奖，突出创意与用户体验。
4. **网络技术挑战赛**
   - **赛制与规则**：2-6人团队，分本科生与研究生组；设创意（A）系列（普通赛项、A-ST网络空间与信息安全赛项、A-ICV车联网赛项）与攻关（B）系列企业命题（可编程网络、工业互联网等）；约2-4月报名、4月资格赛、6月选拔赛、8月底挑战赛（全国总决赛）现场答辩；2025年吸引405所院校、14345人次报名，317件作品进总决赛。
   - **技术栈**：
     ├─ 计算机网络基础（TCP/IP/路由交换/协议分析）
     ├─ 编程与开发（Python/Java/Web前后端）
     ├─ 方向技术
     │  ├─ A-ST：渗透测试/流量分析/安全加固
     │  └─ A-ICV：车联网/交通智能网联
     └─ 企业命题（可编程网络/工业互联网数智应用）
   - **达标建议**：通过资格赛与选拔赛、入围全国挑战赛即获三等奖资格；现场答辩评一/二等奖，对网络、安全、通信专业就业助力大。
5. **人工智能创意赛**
   - **赛制与规则**：浙江大学与百度联合承办，作品须基于百度飞桨及文心大模型技术；初赛（约7月中旬材料截止）、复赛（约9月）、全国总决赛（10-11月，线上评审+现场答辩）；2025年设"飞桨文心"单一赛道，团队不超过3人。
   - **技术栈**：
     ├─ Python与深度学习（飞桨PaddlePaddle）
     ├─ 大模型应用（文心大模型ERNIE/Prompt工程/微调）
     ├─ 应用开发（Web/小程序/端侧部署）
     └─ 创新点提炼与答辩（项目Demo）
   - **达标建议**：完成基于大模型的可运行应用即具备初赛竞争力；进入总决赛并获奖是AI方向求职的好履历。
6. **智能交互创新赛**
   - **赛制与规则**：聚焦人机交互与智能体创新，约4-5月报名（2025年报名截止5月31日）、初赛提交、决赛现场答辩。
   - **技术栈**：
     ├─ 交互设计（用户研究/需求分析/Figma原型）

### 第84项：码蹄杯全国职业院校程序设计大赛
- **简称**：码蹄杯
- **赛道**：数学基础
- **周期**：每年一届
- **时间线**：初赛（省赛）约6-8月（每年3场：职业院校组约6月中/7月初/8月初，本科组对应次日）｜决赛（国赛）约8月底（线下，时间可能逐年变动）
- **难度**：★★★
- **组队**：个人赛为主（1人参赛）
- **适合专业**：计算机、软件及职业院校信息类相关专业（本科院校赛道面向全体本科生/研究生，职业院校赛道面向职教本科/高职高专/技师/中职）
- **简介**：由全国高等学校计算机教育研究会主办、清华大学出版社承办，2023年起纳入全国普通高校竞赛排行榜（职业院校赛道）；采用类ACM赛制在线判题，考察范围与蓝桥杯软件类相近但更贴近职业院校水平；分本科院校、职业院校、青少年挑战三大赛道，同台竞技、分开评奖。

#### 子赛项
1. **初赛（省赛，线上共3场）**
   - **赛制与规则**：线上OJ竞赛（码蹄集系统），每场3小时、程序设计题，类ACM赛制（错误提交即零分、实时榜单）；每年设3场，选手可选1-3场、取最优成绩；支持C、C++、Python、Java；题目难度分青铜/白银/黄金/钻石/星耀五级；省赛获奖比例约50%（金:银:铜=1:2:2），一二等奖晋级国赛。
   - **技术栈**：
     ├─ 算法与数据结构
     │  ├─ 基础算法（模拟/枚举/排序/字符串）
     │  └─ 进阶算法（图论/动态规划/数论）
     ├─ 编程语言（C/C++/Python/Java任选）
     └─ OJ作答策略（按难度分级抢分/罚时管理）
   - **达标建议**：任意一场进入前50%即获省奖；拿到省一等奖（约10%）晋级国赛；对职业院校学生综测与专升本是高性价比选择。
2. **决赛（国赛，线下ACM赛制）**
   - **赛制与规则**：线下集中竞赛，采用国际通用ACM赛制（3小时左右，解题数+罚时排名）；决赛获奖比例约60%（金:银:铜=1:2:3），另设优秀奖、"一血奖"、最佳女选手奖；本科赛道与职业赛道分设奖项；决赛选手可获百度之星等合作赛事推荐名额。
   - **技术栈**：
     ├─ 算法与数据结构（竞赛全体系）
     ├─ 编程语言（C++为主）
     └─ 现场赛状态管理（调试/读题/时间分配）
   - **达标建议**：省一二等奖晋级国赛即达标；国赛获奖（金银铜）作为全国级奖项写入简历，就业与升学认可度高。
3. **青少年挑战赛道（2025年新增）**
   - **赛制与规则**：面向未进入大学阶段的中小学生，分入门组与提高组，与职业院校组/本科组共享赛题、分开评奖，参与初赛与决赛。
   - **技术栈**：
     ├─ 入门组：基础语法与简单算法（C++/Python）
     └─ 提高组：算法与数据结构进阶
   - **达标建议**：以获奖证书和编程能力培养为目标，按组别获奖。
