# 08 土建/水利类竞赛数据（全国普通高校大学生竞赛排行榜 2023版84项，2025沿用）

### 第9项：全国大学生结构设计竞赛
- **简称**：结构赛
- **赛道**：综合（土建）
- **周期**：每年一届
- **时间线**：校赛约4-5月｜省赛（分区赛）约5-7月｜国赛约10月中旬（时间可能逐年变动）
- **难度**：★★★★★
- **适合专业**：土木工程、工程力学、建筑学、交通工程
- **组队**：3人/队（每人限参加1队）
- **简介**：土木工程领域级别最高、参与最广的大学生学科竞赛，2025年第十八届吸引591所高校1792支队伍参加分区赛、119所高校120支队伍晋级国赛；由中国大学生结构设计竞赛委员会主办，获奖与保研、就业直接挂钩，被誉为土木类"国赛"。

#### 子赛项
1. **结构设计赛（主赛）**
   - **赛制与规则**：采用"省（市、自治区）分区赛＋全国总决赛"两级赛制；赛题每年4月发布、方向逐年不同（桥梁/塔/高层/船舶等，如2025年为《乌篷船模型结构设计与制作》）；比赛环节为理论方案设计→现场模型制作→模型称重→加载测试→陈述答辩；省赛现场制作约12小时、国赛约15小时；评分主要看承载力/自重比、结构创新性、制作工艺与现场表现；本科组、专科组分组评审，另设最佳创意奖、最佳制作奖。
   - **技术栈**：
     ├─ 结构分析与设计
     │  ├─ 力学计算（Midas Gen/ABAQUS/SAP2000）
     │  └─ 概念方案（梁/桁架/拱/空间结构选型）
     ├─ 加载试验
     │  ├─ 三级加载测试与称重比优化
     │  └─ 有限元迭代验证
     └─ 答辩展示
        ├─ 理论方案文档与计算书
        └─ 加载数据与创新点陈述
   - **达标建议**：省赛获一等奖可晋级国赛（每省约10-15支）；国赛120支队伍中一、二、三等奖获奖面约70%，特等奖3名以内；冲国赛一等奖需理论方案高分＋模型自重低且顺利通过全部加载工况＋答辩出色，建议校赛起全流程模拟演练至少3轮。
2. **模型制作环节（核心实践环节）**
   - **赛制与规则**：材料由组委会统一提供（竹杆、竹皮、胶水等），限时现场手工制作；模型须满足尺寸、自重与构造规则（如2025年乌篷船模型长960mm/宽320mm/高360mm）；加载前称重并计算荷载比，部分年份含偏心加载、冲击、振动、水浪等附加工况。
   - **技术栈**：
     ├─ 材料工艺
     │  ├─ 竹杆/竹皮裁切、打磨与弯折
     │  └─ 胶接节点与绑扎加固工艺
     ├─ 量测控制
     │  ├─ 电子秤/卡尺/角度仪精度控制
     │  └─ 自重与重心平衡控制
     └─ 试载优化
        ├─ 预加载破坏分析与补强
        └─ 冗余度设计（安全系数）
   - **达标建议**：模型自重明显低于同组平均且顺利通过各级加载即占优；近年国赛一等奖模型自重约100-150g、可承载20-30kg级以上荷载，制作工艺分（平滑度、节点规整度）同样计入评分。

### 第46项：全国高校BIM毕业设计创新大赛
- **简称**：BIM毕设赛
- **赛道**：综合（土建）
- **周期**：每年一届（近年已更名"国际高校BIM毕业设计创新大赛"）
- **时间线**：报名约9-11月｜校园赛/海选晋级赛约11-12月｜全国总决赛作品提交约次年1-4月｜评审答辩约次年5-6月（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：土木工程、工程管理、工程造价、建筑学、智能建造、给排水科学与工程
- **组队**：3-5人/队＋1-2名指导教师（同一队研究生不超过2人，每队限报1个模块）
- **简介**：全国规模最大、涵盖专业最广的建筑类专业赛事之一，第十一届吸引700余所高校、14000余支团队参赛；由中国土木工程学会建筑市场与招标投标研究分会与广联达等主办，采用"校园赛—区域/海选赛—全国总决赛"三级赛制，作品即毕业设计成果，含金量与认可度高。

#### 子赛项
1. **土建/建筑设计BIM应用模块（A模块方向）**
   - **赛制与规则**：常规赛道各模块独立报名、独立评奖，本科组与专科组分别评审；晋级路径为海选赛（线上客观题考试，按成绩排名晋级）或校园赛通道或省赛通道；总决赛以作品形式参赛，提交模型文件＋成果视频＋说明文档，经专家评审；该模块涵盖新型城市基础建设、建筑设计BIM应用等方向。
   - **技术栈**：
     ├─ BIM建模
     │  ├─ Revit建筑/结构建模
     │  └─ 族库与参数化构件创建
     ├─ 深化出图
     │  ├─ CAD平立剖图纸
     │  └─ Navisworks模型检查
     └─ 表达汇报
        ├─ Lumion/Enscape渲染表现
        └─ 成果视频与PPT答辩
   - **达标建议**：海选赛客观题考核专业课程与执业资格考试内容，按模块成绩排名晋级（土建方向晋级名额数百支）；总决赛各模块单独设奖、获奖面较大，冲一等奖需以真实工程项目为背景、完成BIM全流程建模＋渲染视频亮点。
2. **机电设计BIM应用模块**
   - **赛制与规则**：针对暖通、给排水、电气等机电专业，要求完成机电系统BIM建模、管线综合与碰撞检查；赛制同常规赛道（海选/校园赛晋级→总决赛作品评审），各模块独立评奖。
   - **技术栈**：
     ├─ 机电建模
     │  ├─ Revit MEP/MagiCAD建模
     │  └─ 风/水/电系统族构建
     ├─ 管线综合
     │  ├─ 碰撞检查（Navisworks/广联达BIM审模）
     │  └─ 管线综合优化与净高分析
     └─ 出图表达
        ├─ 机电深化图纸
        └─ 综合支吊架布置
   - **达标建议**：海选晋级名额按模块分配（机电模块约200余支）；总决赛获奖面大，冲奖重点在管线综合合理性与碰撞问题闭环处理、展示逻辑清晰。
3. **道桥设计BIM应用模块**
   - **赛制与规则**：面向道路、桥梁、隧道等交通工程方向，要求完成道桥工程BIM建模与设计应用；赛制同常规赛道（晋级赛→总决赛作品评审），本科/专科分别评奖。
   - **技术栈**：
     ├─ 道桥建模
     │  ├─ Civil 3D/Bentley/Revit道桥建模
     │  └─ 地形曲面与路线设计
     ├─ 结构深化
     │  ├─ 桥跨结构与构件深化
     │  └─ 工程量统计
     └─ 成果表达
        ├─ 道桥BIM模型渲染与漫游
        └─ 设计说明书与答辩
   - **达标建议**：海选赛晋级名额约300支；冲奖需体现道桥专业特色（路线、纵断面、桥跨布置与BIM结合深度），提交成果完整度高。
4. **全过程造价管理与成本管控模块（BIM+造价）**
   - **赛制与规则**：围绕工程量计算、招标控制价、全过程造价管理展开，要求基于BIM模型完成造价应用；赛制同常规赛道，各模块独立评奖。
   - **技术栈**：
     ├─ 算量计价
     │  ├─ 广联达GTJ土建算量/GQI安装算量
     │  └─ 广联达GBQ计价与指标分析
     ├─ BIM造价协同
     │  ├─ BIM5D模型-量-价联动
     │  └─ 设计变更与成本管控
     └─ 成果汇报
        ├─ 造价分析报告
        └─ 成本管控方案答辩
   - **达标建议**：海选赛晋级名额约500-560支；冲奖重点为算量计价准确性、指标分析深度与成本管控逻辑，作品需数据可验证。
5. **施工深化设计与管理模块（含施工模拟）**
   - **赛制与规则**：要求完成施工深化设计、施工进度计划、施工现场布置与BIM施工模拟，展示施工阶段BIM应用价值；赛制同常规赛道（晋级赛→总决赛），本科/专科独立评奖。
   - **技术栈**：
     ├─ 施工深化
     │  ├─ 深化设计建模（Revit）
     │  └─ 施工图深化与节点详图
     ├─ 施工模拟
     │  ├─ BIM5D进度-成本模拟
     │  └─ Navisworks/广联达施工模拟动画
     └─ 现场管理
        ├─ 场地布置与临建规划
        └─ 进度计划（斑马进度/Project）
   - **达标建议**：海选赛晋级名额较多（约550支）；冲奖需施工模拟动画流畅、进度与模型联动闭环、现场管理逻辑落地。
6. **建筑碳排放计算与减碳设计模块**
   - **赛制与规则**：围绕建筑全生命周期碳排放计算与减碳设计策略展开，要求完成碳排放核算与减碳方案；赛制同常规赛道，各模块独立评奖。
   - **技术栈**：
     ├─ 碳排放核算
     │  ├─ 建材/建造/运行阶段碳排放计算
     │  └─ Green Building Studio/国产绿建软件
     ├─ 减碳设计
     │  ├─ 被动式节能与可再生能源方案
     │  └─ 绿建标准（GB/T 51366等）对标
     └─ 成果输出
        ├─ 碳排放分析报告
        └─ 减碳策略与答辩
   - **达标建议**：紧扣政策热点、核算依据充分是拿分关键；冲一等奖需模型数据完整、计算口径符合规范并给出可落地的减碳措施。

### 第60项：全国大学生水利创新设计大赛
- **简称**：水利创新赛
- **赛道**：综合（水利）
- **周期**：每两年一届（2025年为第九届）
- **时间线**：校赛约3-4月｜报名与作品提交约4-5月｜网络初评约5-6月｜现场决赛约7月中旬（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：水利水电工程、水文与水资源工程、港口航道与海岸工程、农业水利工程、环境工程
- **组队**：≤5人/队（决赛现场≤3人，指导教师≤2人）
- **简介**：全国水利类大学生的"奥林匹克"竞赛，由中国水利教育协会主办、河海大学等水利类高校承办，第九届（2025年）160所高校428组作品参赛；以实物创新作品＋答辩模式进行，强调新质生产力与智慧水利方向，含金量与认可度高。

#### 子赛项
1. **实物创新作品赛（主赛）**
   - **赛制与规则**：围绕当届主题自选课题（如第九届"新质生产力驱动下的智慧水利创新设计"，历届还有"智慧水利""新阶段 新水利"），设计并制作实物作品；校级选拔后每校最多推荐3件（承办校4件）；提交报名表＋完整设计说明书与图纸（PDF）＋3分钟以内功能演示视频；经网络初评晋级现场决赛；评审指标为科学性、可行性、创新性、实用性；作品须原创，实物体积不超过2立方米、最长边不超过2米。
   - **技术栈**：
     ├─ 设计建模
     │  ├─ CAD/SolidWorks/Rhino三维建模
     │  └─ 水动力仿真（FLOW-3D/ANSYS/HEC-RAS）
     ├─ 实物制作
     │  ├─ 亚克力/3D打印/模型加工
     │  └─ 传感器与单片机（水位/水质/流量监测）
     └─ 成果输出
        ├─ 设计说明书与图纸
        └─ 演示视频（3分钟内，MP4）
   - **达标建议**：网评晋级现场决赛比例约40%（第九届428组晋级168组）；决赛特等奖≤15%、一等奖≤30%、二等奖≤35%，晋级现场基本可获得二等奖及以上；冲特等奖需创新点明确、实物功能演示可靠。
2. **现场决赛（实物展示与现场答辩）**
   - **赛制与规则**：决赛在承办高校现场举行（2025年第九届于7月15-17日在江苏科技大学举办）；参赛队伍现场布置展位、实物运行演示，并进行PPT汇报与专家质询答辩；现场参赛学生不超过3人、指导教师1人；另设优秀指导教师奖、优秀组织奖。
   - **技术栈**：
     ├─ 汇报展示
     │  ├─ PPT/展板/实物运行演示
     │  └─ 试验数据与对比分析图表
     └─ 答辩准备
        ├─ 创新点与工程实用性论证
        └─ 专家质询模拟训练
   - **达标建议**：答辩重点突出创新性、可推广性与工程价值，实物演示稳定流畅；特等奖需创新点鲜明＋数据支撑完整＋应答自信。

### 第64项：全国大学生花园设计建造竞赛
- **简称**：花园建造赛
- **赛道**：综合（风景园林）
- **周期**：每年一届
- **时间线**：主赛道：方案征集约1-3月｜线上终评答辩约3月｜现场建造与评审约5月；社区花园赛道：报名约10月｜评审约11月（时间可能逐年变动）
- **难度**：★★★★
- **适合专业**：风景园林、园林、城乡规划、建筑学、环境设计
- **组队**：主赛道4-6人/队（含指导教师1名）；社区花园赛道3-7人/队
- **简介**：国内唯一以花园设计建造为主题的国家级高校竞赛，由北京林业大学首创、中国风景园林学会指导，前身为"北林-南森"国际花园设计建造大赛；以竹构建造为特色，2024年升级为成都世界园艺博览会专项竞赛之一，2025年起增设社区花园赛道，认可度逐年提升。

#### 子赛项
1. **主赛道（花园方案设计＋现场建造）**
   - **赛制与规则**：三个阶段：方案设计征集评选→入选作品施工图绘制与可行性对接→现场建造、评奖与展览；参赛对象为风景园林及相关专业本科生、研究生，鼓励跨专业组队；作品须由团队成员亲自完成现场搭建（现场限1名指导老师＋6名成员）；以2024年为例，394份有效作品经初评复评、线上终评答辩三轮投票，前20组进入实地建造评奖，21-35名获三等奖、36-45名获入围奖。
   - **技术栈**：
     ├─ 方案设计
     │  ├─ SketchUp/Rhino概念建模
     │  └─ CAD总平面与效果图（Lumion/Enscape）
     ├─ 施工图深化
     │  ├─ 竹构节点大样与构造图纸
     │  └─ 材料用量与可建造性校核
     └─ 现场建造
        ├─ 竹材加工（原竹/竹片/竹篾绑扎）
        └─ 现场施工组织与安全管控
   - **达标建议**：方案从394份中入选前20组进入实地建造即基本锁定二三等奖，前5名左右可冲一等奖；核心是方案创意＋竹构可行性＋现场建造完成度；竹构筑物限高5m、占地≤20㎡，辅材不超过30%。
2. **社区花园赛道（2025年起新增）**
   - **赛制与规则**：面向社区更新场景，两个阶段：方案设计征集评选（确定获奖作品）＋颁奖，无需长途现场建造，成果在社区落地展示并自主运维不少于7天；鼓励跨学院、跨专业、跨年级组队；材料以可回收、可降解材料为主，面积推荐5-20平方米。
   - **技术栈**：
     ├─ 场地调研与方案
     │  ├─ 社区现状调研与人群分析
     │  └─ SketchUp/手绘方案推演
     ├─ 可回收材料建造
     │  ├─ 低成本材料与模块化构件
     │  └─ 社区共建与居民参与策划
     └─ 运维展示
        ├─ 落地实施与养护计划
        └─ 过程记录与成果汇报
   - **达标建议**：2026年首届社区花园赛道报名截止约10月、11月评审；获奖重点在社区需求契合度、材料可回收性与落地可实施性，突出共建共治亮点更易冲奖。

### 第75项：全国数字建筑创新应用大赛
- **简称**：数字建筑赛
- **赛道**：综合（土建）
- **周期**：每年一届
- **时间线**：报名约4-8月｜全国选拔赛约9月（线上）｜全国总决赛约10月（线上）（时间可能逐年变动）
- **难度**：★★★
- **适合专业**：土木工程、工程造价、工程管理、智能建造、建筑学
- **组队**：3人/队＋1-2名指导教师（以二级院系为单位报名，同一单位每赛项最多3队）
- **简介**：中国建设教育协会主办、广联达等协办的数字建筑应用型赛事，已连续举办17届、累计超20万师生参与；以广联达软件平台为核心，考查BIM建模、施工管理与工程造价实战能力，获奖可申领《住房城乡建设领域BIM应用专业技能证书》，是软件技能类性价比高的排行榜赛事。

#### 子赛项
1. **BIM数维设计建模赛项**
   - **赛制与规则**：考试科目为BIM公建建模、BIM住宅建模，线上机考（广联达数字考试平台）；两阶段赛制：全国选拔赛（线上考核选拔，开启摄像头全程监控）→全国总决赛（选拔赛总成绩前70%的团队参加，成员不可更换）；本科组、专科组分别报名、单独排名。
   - **技术栈**：
     ├─ BIM建模
     │  ├─ 广联达数维/Revit建筑建模
     │  └─ 平立剖图与构件布置
     ├─ 模型深化
     │  ├─ 参数化构件与族编辑
     │  └─ 模型质量与出图校审
     └─ 应试训练
        ├─ 真题限时训练（公建/住宅科目）
        └─ 快捷键与建模效率优化
   - **达标建议**：选拔赛前70%可进总决赛，最终获奖约一等奖15%、二等奖25%、三等奖30%（获奖比例较高）；冲奖关键在于建模速度与准确性，建议赛前完成20套以上限时模拟。
2. **数字施工项目管理综合应用赛项**
   - **赛制与规则**：考试科目涵盖BIM建模、BIM施工现场规划、工程进度计划管理、BIM施工管理、BIM施工工艺模拟；赛制同两阶段线上赛（选拔赛→总决赛），本科/专科分组评奖。
   - **技术栈**：
     ├─ 施工BIM应用
     │  ├─ 施工阶段BIM建模与深化
     │  └─ BIM施工现场布置（广联达场布）
     ├─ 进度与模拟
     │  ├─ 进度计划编制（斑马进度/Project）
     │  └─ BIM施工工艺模拟动画
     └─ 项目管理
        ├─ 施工管理业务流程
        └─ 案例实操与应试训练
   - **达标建议**：选拔赛前70%晋级总决赛；获奖重点在施工工艺模拟完整性、现场布置合理性与进度逻辑正确，各科目均衡得分更有把握。
3. **建设工程计量与计价应用赛项（数字造价）**
   - **赛制与规则**：考试科目为建设工程计量、建设工程计价，重点考核建筑与装饰计量、电气与给排水专业计量、土建工程招标控制价、安装工程招标控制价编制；赛制同两阶段线上赛，本科/专科分组评奖。
   - **技术栈**：
     ├─ 计量算量
     │  ├─ 广联达GTJ土建算量/GQI安装算量
     │  └─ 清单工程量计算规则应用
     ├─ 计价编制
     │  ├─ GBQ计价软件与清单组价
     │  └─ 招标控制价编制
     └─ 应试训练
        ├─ 定额与清单规范记忆
        └─ 限时案例题训练
   - **达标建议**：选拔赛前70%晋级；获奖关键在计量准确率与计价规则掌握，建议重点训练土建+安装两类控制价编制真题，冲一等奖需整体正确率高。
